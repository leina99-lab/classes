## 1.  세 회귀를 한 줄에 놓는다 (각 1점, 총 8점)

## 2.  Errors-in-Variables 모형 (각 2점, 총 16점)

OLS 가 가정하는 \"X 는 (㉠) 측정되고 오차는 오직 (㉡) 에만 있다\" 라는 가정은 많은 실무 상황에서 깨진다. 그때의 정확한 모형은 다음 EIV 모형이다.

$$ X_i = \xi_i + (㉢), \qquad Y_i = \eta_i + (㉣), \qquad \eta_i = \beta_0 + \beta_1 (㉤). $$

여기서 $(\xi_i, \eta_i)$ 는 관측되지 않는 (㉥) 이고, $X_i, Y_i$ 는 그 (㉥) 에 측정오차가 더해진 (㉦) 이다.

OLS 가 EIV 모형에서 일으키는 문제는 \"(㉧) 편향\" — 기울기 추정값이 참값보다 (㉨) 쪽으로 끌려가는 현상이다.

## 3.  핵심 모수 — 분산비 $\lambda$ (각 2점, 총 12점)

Deming 회귀의 핵심 모수는

$$ \lambda = \frac{(㉠)}{(㉡)}. $$

이는 \"Y 의 오차분산이 X 의 오차분산보다 (㉢) 배 큰가\" 를 가리킨다.

| $\lambda$ | 직관 | 결과 |
|---|---|---|
| $\lambda \to \infty$ | Y 오차가 X 오차보다 압도적 | (㉣) 와 일치 |
| $\lambda = 1$ | 두 오차가 동일 분산 | (㉤) 회귀 = PCA 첫 주성분 |
| $\lambda \to 0$ | X 오차가 압도적 | (㉥) OLS |

## 4.  무엇을 최소화하는가 (각 2점, 총 10점)

Deming 회귀의 목적함수는 다음과 같다.

$$
S(\beta_0, \beta_1, \{\xi_i\}) = \sum_{i=1}^{n} \left[
\frac{\bigl(X_i - (㉠)\bigr)^2}{(㉡)}
\;+\;
\frac{\bigl(Y_i - \beta_0 - \beta_1 (㉠)\bigr)^2}{(㉢)}
\right]
$$

분모로 각 오차의 (㉣) 을 두는 이유는 \"단위가 다른 두 잔차를 같은 (㉤) 에서 비교\" 하기 위함이다.

## 5.  닫힌 해 (각 2점, 총 6점)

목적함수의 편미분 = 0 을 풀면 다음 닫힌 해가 얻어진다.

$$
\hat\beta_1 = \frac{S_{yy} - \lambda S_{xx} + \sqrt{(S_{yy} - \lambda S_{xx})^2 + 4\lambda S_{xy}^{\,2}}}{(㉠)}, \qquad \hat\beta_0 = \bar y - \hat\beta_1 \cdot (㉡).
$$

복잡해 보이지만, 결국 \"(㉢) = 0\" 이라는 한 줄에서 자동으로 따라 나오는 식이다.

## 6.  $\lambda = 1$ 의 특별한 의미 (각 2점, 총 10점)

$\lambda = 1$ 일 때 Deming 회귀는 (㉠) 회귀 — 즉 회귀선과 각 점의 (㉡) 거리 제곱합을 최소화한다. 그리고 이 결과는 정확히 (㉢) 의 제 1 주성분 방향과 같다.

직관적으로:

- $\lambda = 1$ → 두 변수의 단위가 \"오차 측면에서\" 같은 (㉣).
- 가중 직교 거리 = 평범한 (㉤) 거리.

## 7.  scipy.odr 코드 빈칸 (각 2점, 총 14점)

```python
import numpy as np
from scipy import odr
from sklearn.linear_model import LinearRegression

X_obs, Y_obs = ...   # 두 측정기기의 자료
sigma_X, sigma_Y = 0.8, 1.5

# 1) 모형 정의
def linear_model(B, x):
    return (㉠) + (㉡) * x

linear = odr.Model(linear_model)

# 2) 두 변수의 측정오차를 명시
data = odr.RealData(X_obs, Y_obs, sx=(㉢), sy=(㉣))

# 3) 초기값 — OLS 결과 사용
ols = LinearRegression().fit(X_obs.reshape(-1, 1), Y_obs)
init = [ols.(㉤), ols.coef_[0]]

# 4) 실행
out = odr.ODR(data, linear, beta0=init).run()
beta0_hat, beta1_hat = out.(㉥)
print(beta0_hat, beta1_hat)
```

추가로, $\lambda = \mathrm{Var}(\varepsilon)/\mathrm{Var}(\delta) = $ (㉦)² / sigma_X² 라는 관계를 머리에 두면 `sx`, `sy` 두 값으로 $\lambda$ 가 자동으로 결정됨을 알 수 있다.

## 8.  Deming 회귀의 사용 시점 (각 2점, 총 10점)

다음 다섯 상황에서 OLS 대신 Deming 이 적절하다.

1. (㉠) — 의학 임상 검사, 산업 계측기 교정.
2. 시약·물질 간의 정량적 비교 — 두 분석법의 (㉡).
3. (㉢) — test-retest 신뢰도.
4. 두 (㉣) 평가의 비교 — 둘 다 평가에 오차를 가진다.
5. 동일 시료를 두 방법으로 측정하는 (㉤) 비교.

공통점: \"X 와 Y 가 (㉥) 비대칭이 없는 두 측정\" 이라는 것이다.

## 9.  OX 문제 (각 2점, 총 10점)

| | 문장 | OX |
|---|---|---|
| (1) | OLS 의 \"감쇠 편향\" 은 X 에 측정오차가 있을 때 일어난다. | |
| (2) | Deming 회귀는 \"수직 잔차\" 제곱합을 최소화한다. | |
| (3) | $\lambda \to \infty$ 인 극한에서 Deming 의 결과는 OLS 와 일치한다. | |
| (4) | $\lambda = 1$ 일 때 Deming 의 결과는 PCA 의 제 1 주성분 방향과 같다. | |
| (5) | $\lambda$ 의 값은 자료가 알려주는 모수이므로 분석자가 정할 필요 없다. | |
