## Part 6.  OX 문제 (10점)

다음 문장이 맞으면 ○, 틀리면 × 를 적으시오.

| | 문장 | OX |
|---|---|---|
| (1) | Deming 회귀는 X 에 측정오차가 있을 때만 의미가 있다. | |
| (2) | $\lambda \to \infty$ 일 때 Deming 의 결과는 OLS 와 같아진다. | |
| (3) | Deming 회귀는 \"수직 잔차\" 의 제곱합을 최소화한다. | |
| (4) | 두 변수의 측정 오차 분산이 같으면 Deming 의 결과는 PCA 제 1 주성분과 같다. | |
| (5) | OLS 의 감쇠 편향은 X 의 측정 표준편차가 클수록 심해진다. | |
