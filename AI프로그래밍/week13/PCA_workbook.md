## 1.  왜 PCA 를 OLS 다음에 배우는가 (각 1점, 총 4점)

PCA 는 OLS 와 같은 사고방식 \"손실함수를 편미분 = 0\" 에서 출발한다. 다만 두 가지가 추가된다.

1. **목적함수가 최소화에서 (㉠) 로 바뀐다** — 분산을 (㉠) 로 만든다.
2. **(㉡) 가 등장한다** — 방향벡터의 크기가 (㉢) 이어야 한다.

(㉡) 가 있는 최적화는 (㉣) 승수법으로 다룬다.

## 2.  무엇을 최대화하는가 (각 2점, 총 10점)

자료 $\boldsymbol X$ 가 중심화되어 있을 때, 단위벡터 $\boldsymbol v$ 방향으로 사영한 자료 $\boldsymbol{X v}$ 의 표본 분산은

$$ \mathrm{Var}(\boldsymbol{X v}) = (㉠), \qquad (㉡) = \frac{1}{n-1}\boldsymbol{X}^{\mathsf T}\boldsymbol{X}. $$

PCA 가 푸는 문제는

$$ \max_{\boldsymbol v} \;\; (㉢) \quad \text{subject to} \quad (㉣) = 1. $$

크기 제약이 없으면 분산은 (㉤) 로 커질 수 있으므로 단위벡터로 고정한다.

## 3.  라그랑주 함수와 편미분 (각 2점, 총 12점)

제약 있는 최적화의 라그랑주 함수는

$$ L(\boldsymbol{v}, \lambda) = (㉠) - \lambda\bigl((㉡) - 1\bigr). $$

$\lambda$ 는 (㉢) 승수 — 지금은 아직 미지수이다.

$\boldsymbol{v}$ 에 대해 편미분을 0 으로 놓는다.

$$ \frac{\partial L}{\partial \boldsymbol{v}} = 2(㉣) - 2\lambda(㉤) = \boldsymbol{0}. $$

정리하면

$$ \boxed{\;(㉥)\;} $$

이 식은 공분산행렬 $\Sigma$ 의 (㉦) - (㉧) 방정식이다.

## 4.  두 결론 (각 2점, 총 10점)

위 결과로부터 자동으로 두 가지가 따라온다.

1. $\boldsymbol{v}$ 는 $\Sigma$ 의 (㉠) 이다 — 즉 주성분 (㉡) 이다.
2. $\lambda$ 가 곧 (㉢) 이다.  
   증명: $\Sigma\boldsymbol{v} = \lambda\boldsymbol{v}$ 의 양변에 $\boldsymbol{v}^{\mathsf T}$ 를 곱하고 제약 $\boldsymbol{v}^{\mathsf T}\boldsymbol{v} = 1$ 을 적용하면 $\boldsymbol{v}^{\mathsf T}\Sigma\boldsymbol{v} = $ (㉣).

따라서 (㉤) 고유값에 대응하는 고유벡터가 제 1 주성분이다.

## 6.  표준화는 왜 거의 필수인가 (각 2점, 총 6점)

PCA 는 \"(㉠) 이 큰 방향\" 을 찾는다. 변수의 (㉡) 가 다르면 (㉡) 가 큰 변수가 결과를 지배한다. 거의 모든 실무 상황에서 PCA 직전에 (㉢) 로 평균 0, 표준편차 1 로 표준화한다.

## 8.  PCA 의 네 가지 사용 시점 (각 2점, 총 8점)

PCA 를 쓸 만한 자리는 다음 네 가지이다.

1. (㉠) — 변수가 너무 많을 때 정보 손실을 최소화하며 줄인다.
2. (㉡) — 고차원 자료를 2~3 차원으로 사영해 군집·이상치를 본다.
3. (㉢) — 회귀의 설명변수들이 강한 상관을 가질 때 주성분을 회귀변수로 쓴다 (주성분 회귀, PCR).
4. (㉣) — 분산이 작은 후순위 주성분은 잡음일 가능성이 크므로 잘라낸다.

## 10.  OX 문제 (각 2점, 총 12점)

| | 문장 | OX |
|---|---|---|
| (1) | PCA 의 제 1 주성분은 자료의 분산이 가장 큰 방향이다. | |
| (2) | 라그랑주 승수 $\lambda$ 는 사영 후 분산값과 같다. | |
| (3) | 단위가 다른 변수에 PCA 를 적용할 때 표준화 없이 진행해도 된다. | |

| (5) | PCA 와 OLS 의 회귀선은 같은 자료에서 항상 일치한다. | |
| (6) | Kaiser 기준은 고유값이 1 이상인 주성분을 선택한다. | |
