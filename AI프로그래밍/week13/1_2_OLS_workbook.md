## 2.  손실함수와 편미분 (각 2점, 총 16점)

OLS 의 손실함수는 다음과 같다.

$$ S(\beta_0, \beta_1) = \sum_{i=1}^{n} \bigl(\;(㉠) - (㉡) - (㉢)\;\bigr)^{2} $$

이는 두 변수 $\beta_0, \beta_1$ 에 대한 매끄러운 (㉣) 차 함수이므로 임계점이 곧 (㉤) 이다. 두 변수 각각에 대한 편미분을 0 으로 놓는다.

$$ \frac{\partial S}{\partial \beta_0} = -2 \sum_i \bigl(\;(㉥)\;\bigr) = 0 $$

$$ \frac{\partial S}{\partial \beta_1} = -2 \sum_i (㉦)\bigl(\;(㉧)\;\bigr) = 0 $$

## 3.  닫힌 형태의 해 (각 2점, 총 12점)

정규방정식을 풀면

$$ \hat\beta_1 = \frac{(㉠)}{(㉡)}, \qquad \hat\beta_0 = (㉢) - \hat\beta_1 \cdot (㉣). $$

이 식은 다음과 같이 읽는다.

- **분자** $\sum (x_i - \bar x)(y_i - \bar y)$ 는 $x$ 와 $y$ 의 (㉤) 분자이다.
- **분모** $\sum (x_i - \bar x)^2$ 는 $x$ 의 (㉥) 분자이다.

## 6.  Gauss-Markov 정리의 다섯 가정 (각 1점, 총 9점)

다음 다섯 가정이 성립할 때 OLS 의 추정량은 BLUE 이다.

1. (㉠) — 모형이 모수에 대해 선형이다.
2. (㉡) — $\mathbb{E}[\delta_i \mid X_i] = 0$.
3. (㉢) — $\mathrm{Var}(\delta_i) = \sigma^2$ 가 모든 $i$ 에서 같다.
4. (㉣) — 잔차들끼리 상관이 없다.
5. X 에 (㉤) 가 없다.

## 8.  OX 문제 (각 2점, 총 10점)

| | 문장 | OX |
|---|---|---|
| (1) | OLS 의 손실함수는 잔차의 절댓값 합을 최소화한다. | |
| (2) | OLS 의 정규방정식은 손실함수를 편미분하여 0 으로 놓아 얻는다. | |
| (3) | $\boldsymbol{X}^{\mathsf T}\boldsymbol{X}$ 의 역행렬이 존재하지 않으면 OLS 의 해가 유일하지 않다. | |
| (4) | OLS 는 X 에 측정오차가 있을 때에도 비편향이다. | |
| (5) | $\hat\beta_1$ 의 부호가 양이면 $x$ 와 $y$ 의 공분산이 양이다. | |
