## Part 6.  OX 문제 (10점)

다음 문장이 맞으면 ○, 틀리면 × 를 적으시오.

| | 문장 | OX |
|---|---|---|
| (1) | OLS 의 손실함수는 잔차의 제곱이 아닌 절댓값의 합을 최소화한다. | |
| (2) | OLS 의 정규방정식은 손실함수를 편미분해서 0 으로 놓아 얻는다. | |
| (3) | $\boldsymbol{X}^{\mathsf T}\boldsymbol{X}$ 의 역행렬이 존재하지 않으면 OLS 의 해가 유일하지 않다. | |
| (4) | OLS 는 X 에도 측정오차가 있을 때 비편향 추정량을 제공한다. | |
| (5) | $\hat\beta_1$ 의 부호가 양이면 $x$ 와 $y$ 의 공분산이 양이다. | |

## Part 7.  도구 선택 (10점)

다음 다섯 상황 각각에서 OLS 가 적절한지 (O / △ / ×) 로 표시하고, 이유를 한 줄로 적으시오.

| 상황 | O/△/× | 이유 |
|---|---|---|
| (가) 키로부터 몸무게를 예측. 키는 측정오차가 작다고 본다. | | |
| (나) 두 측정기기의 \"같음\" 을 비교. 두 기기 모두 오차를 가진다. | | |
| (다) 시간(t) 에 대한 매출액 추세 예측. 시간은 정확히 안다. | | |
| (라) 50 개 시험 점수로 전공 적합도 회귀. 시험들이 강한 상관을 가진다. | | |
| (마) 한 변수의 측정 단위가 cm, 다른 변수의 단위가 만 원이다. | | |
