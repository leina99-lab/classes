결과 칸을 클릭하면 원본 배열의 어느 칸이 계산에 참여했는지, 실제 식이 어떻게 만들어지는지 확인한다.

행렬곱: 결과 한 칸은 “A의 행”과 “B의 열”의 내적이다

C의 칸을 클릭하라. A의 해당 행, B의 해당 열이 강조되고, 각 곱셈 항이 아래 식으로 나타난다.

A
@
B
=
C
C의 칸을 클릭하면 계산 경로가 표시된다.
A * B와 A @ B는 다르다. `A * B`는 같은 위치끼리 곱한다. `A @ B`는 A의 한 행과 B의 한 열을 마주 보게 하여 곱하고 모두 더한다. 부울곱 모드에서는 곱셈 대신 AND, 덧셈 대신 OR를 사용한다.

브로드캐스팅: 결과 한 칸은 원본 배열의 어느 칸에서 왔는가

C의 칸을 클릭하라. A와 B에서 실제로 참조되는 원본 칸이 강조된다. “반복”은 실제 복사가 아니라 같은 칸을 다시 읽는다는 뜻이다.

NumPy는 필요 없는 실제 복사를 피하고 계산 시점에 맞춰 읽는다.
C의 칸을 클릭하면 A와 B의 원본 참조 위치가 표시된다.

신경망 연결: X @ W + b에서 b는 어떻게 모든 샘플에 더해지는가

이 탭은 브로드캐스팅의 응용이다. `X @ W`의 각 행은 샘플 하나이고, `b`는 뉴런별 편향이다. b의 같은 값이 모든 샘플 행에 반복 적용된다.
