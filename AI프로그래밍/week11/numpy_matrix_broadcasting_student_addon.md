# NumPy 계산 경로 해부 보강: 행렬곱과 브로드캐스팅

이 보강 자료는 `shape`를 맞히는 데서 끝나지 않는다. 결과의 한 칸이 어떤 원본 칸에서 왔는지, 실제 계산식이 어떻게 만들어지는지를 추적한다.

---

## 1. 행렬곱 `A @ B`

행렬곱에서 가장 중요한 문장은 다음이다.

> 결과 행렬 `C`의 한 칸 `C[i, j]`는 `A`의 `i`번 행과 `B`의 `j`번 열을 마주 보게 하여 곱하고 모두 더한 값이다.

수식으로는 다음과 같다.

$$
C[i,j] = \sum_{k=0}^{r-1} A[i,k]B[k,j]
$$

여기서 `A.shape = (m, r)`이고 `B.shape = (r, n)`이면 결과는 `C.shape = (m, n)`이다. 가운데 차원 `r`은 서로 같아야 한다.

```python
import numpy as np

A = np.array([[1, 2, 3],
              [4, 5, 6]])

B = np.array([[7, 8],
              [9, 10],
              [11, 12]])

C = A @ B
print(C)
```

결과는 다음이다.

```text
[[ 58  64]
 [139 154]]
```

예를 들어 `C[0, 1]`은 다음처럼 계산된다.

$$
C[0,1] = 1\times 8 + 2\times 10 + 3\times 12 = 64
$$

즉, `C[0, 1]`은 다음 세 항의 합이다.

```text
A[0,0] × B[0,1] = 1 × 8
A[0,1] × B[1,1] = 2 × 10
A[0,2] × B[2,1] = 3 × 12
```

따라서 행렬곱은 같은 위치끼리 곱하는 연산이 아니다. 같은 위치끼리 곱하는 것은 `A * B`이다. 행렬곱은 `A @ B`이다.

## 2. 부울곱과 일반 행렬곱의 차이

부울곱은 일반 행렬곱과 모양은 비슷하지만 연산이 다르다.

일반 행렬곱은 다음과 같다.

```text
곱한다 → 더한다
```

부울곱은 다음과 같다.

```text
AND 한다 → OR 한다
```

즉, 부울곱에서 결과 `C[i, j]`는 다음처럼 계산된다.

$$
C[i,j] = (A[i,0] \land B[0,j]) \lor (A[i,1] \land B[1,j]) \lor \cdots
$$

이 방식은 그래프의 인접행렬에서 “길이 2인 경로가 있는가”를 확인할 때 자주 등장한다.

## 3. 브로드캐스팅의 핵심 원리

브로드캐스팅은 shape가 다른 배열을 함께 계산할 수 있게 해 주는 NumPy의 규칙이다. 핵심은 다음이다.

> 두 배열의 shape를 오른쪽 끝 차원부터 비교한다. 두 차원이 같거나, 둘 중 하나가 1이면 계산할 수 있다.

규칙은 다음 순서로 적용된다.

```text
1. 차원 수가 다르면 작은 쪽의 앞에 1을 붙여서 맞춘다.
2. 오른쪽 끝 차원부터 비교한다.
3. 두 차원이 같으면 그대로 사용한다.
4. 둘 중 하나가 1이면 그쪽 값을 반복해서 사용한다.
5. 두 차원이 다르고 어느 쪽도 1이 아니면 실패한다.
```

중요한 점은 “반복”이라는 말이 실제로 큰 배열을 복사한다는 뜻은 아니라는 것이다. 처음 이해할 때는 복제된다고 생각해도 좋지만, 실제 NumPy는 필요 없는 메모리 복사를 피하고 계산할 때 같은 값을 다시 읽는 방식으로 작동한다.

---

## 4. 행 벡터 브로드캐스팅: `(2, 3) + (3,)`

```python
A = np.array([[1, 2, 3],
              [4, 5, 6]])

b = np.array([10, 20, 30])

C = A + b
```

shape 비교는 다음과 같다.

```text
A.shape = (2, 3)
b.shape =    (3,)

앞에 1을 붙여 맞추면
A.shape = (2, 3)
b.shape = (1, 3)
```

마지막 차원은 `3`과 `3`이므로 같다. 첫 번째 차원은 `2`와 `1`이다. `1`인 쪽은 반복될 수 있으므로 계산이 가능하다.

결과는 다음이다.

```text
[[11, 22, 33],
 [14, 25, 36]]
```

예를 들어 `C[1, 2]`는 다음처럼 계산된다.

$$
C[1,2] = A[1,2] + b[2] = 6 + 30 = 36
$$

여기서 `b[2]`는 모든 행에서 다시 사용된다.

---

## 5. 열 벡터 브로드캐스팅: `(2, 3) + (2, 1)`

```python
A = np.array([[1, 2, 3],
              [4, 5, 6]])

col = np.array([[100],
                [200]])

C = A + col
```

shape 비교는 다음과 같다.

```text
A.shape   = (2, 3)
col.shape = (2, 1)
```

첫 번째 차원은 `2`와 `2`이므로 같다. 두 번째 차원은 `3`과 `1`이다. `1`인 쪽이 반복될 수 있으므로 계산이 가능하다.

예를 들어 `C[1, 2]`는 다음처럼 계산된다.

$$
C[1,2] = A[1,2] + col[1,0] = 6 + 200 = 206
$$

여기서 `col[1,0]`은 1번 행의 모든 열에 반복된다.

---

## 6. 바깥합: `(4, 1) + (3,)`

이 예제는 브로드캐스팅을 이해하는 데 매우 중요하다. 한쪽만 커지는 것이 아니라 양쪽이 서로 다른 방향으로 확장된다.

```python
A = np.array([[0],
              [10],
              [20],
              [30]])       # shape (4, 1)

b = np.array([1, 2, 3])     # shape (3,)

C = A + b
```

shape는 다음처럼 맞춰진다.

```text
A.shape = (4, 1)
b.shape =    (3,)

앞에 1을 붙이면
A.shape = (4, 1)
b.shape = (1, 3)

결과 shape = (4, 3)
```

결과 `C[2, 1]`은 다음처럼 계산된다.

$$
C[2,1] = A[2,0] + b[1] = 20 + 2 = 22
$$

이 예제에서 `A`는 가로 방향으로 반복되고, `b`는 세로 방향으로 반복된다. 그래서 결과는 4행 3열이 된다.

---

## 7. 실패 예제: `(4, 3) + (4,)`

많은 학생이 다음 코드를 가능하다고 생각한다.

```python
A = np.zeros((4, 3))
b = np.array([100, 200, 300, 400])

A + b
```

그러나 이것은 실패한다.

shape 비교는 다음과 같다.

```text
A.shape = (4, 3)
b.shape =    (4,)

앞에 1을 붙이면
A.shape = (4, 3)
b.shape = (1, 4)
```

오른쪽 끝 차원에서 `3`과 `4`가 만난다. 두 값은 같지 않고, 어느 쪽도 `1`이 아니다. 따라서 브로드캐스팅이 불가능하다.

수정하려면 `b`를 열 벡터로 바꿔야 한다.

```python
b_col = b.reshape(4, 1)
A + b_col
```

이제 shape는 다음과 같다.

```text
A.shape     = (4, 3)
b_col.shape = (4, 1)
```

두 번째 차원에서 `1`이 반복될 수 있으므로 계산이 가능하다.

## 8. 신경망 편향 덧셈과 브로드캐스팅

신경망의 한 층은 보통 다음 형태로 계산된다.

$$
Z = XW + b
$$

여기서 shape는 다음과 같다.

```text
X.shape = (샘플 수, 입력 특성 수)
W.shape = (입력 특성 수, 뉴런 수)
b.shape = (뉴런 수,)
```

예를 들어 다음과 같다.

```text
X.shape = (32, 784)
W.shape = (784, 128)
X @ W   = (32, 128)
b.shape = (128,)
```

`X @ W + b`에서 `b`는 `(128,)`이므로 앞에 1을 붙여 `(1, 128)`처럼 생각할 수 있다. 따라서 `32`개 샘플 행 전체에 같은 편향 벡터가 반복되어 더해진다.

즉, 브로드캐스팅은 신경망에서 편향을 모든 샘플에 한 번에 더하는 핵심 원리이다.
