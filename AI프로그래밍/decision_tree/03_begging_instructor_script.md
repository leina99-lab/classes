**칠판/슬라이드용 도식**:

```
구조적 결측 (structural)        진짜 누락 (missing at random)
─────────────────────────       ──────────────────────────
"수영장 없음" → NA              측정자가 빠뜨림
"차고 없음"   → NA              데이터 입력 오류
"지하실 없음" → NA              

처리: fillna("None")           처리: fillna(중앙값) 또는
      → 카테고리로                   groupby 기반 채우기
```

**Ping 7 시연 포인트** (5분):

**Pong 6 함정**:

### 7장 `groupby`로 집단별 패턴 발견하기

**Ping 12 시연 포인트** (8분):
- 동네별 가격표를 띄우고 *최고 동네와 최저 동네의 비율*을 학생에게 암산시킬 것 ("약 3배"). 이를 통해 *입지의 위력*을 체감시킨다.
- `agg(["mean", "median", "count"])` 다중 통계 문법을 명시적으로 가리킬 것. pandas 복습의 핵심.

**Pong 12 함정**:
- `transform("median")`과 `agg("median")`의 차이가 가장 큰 혼란 지점.
- 칠판에 그림:
  ```
  groupby(...).agg("median")        → 그룹 수만큼 짧은 결과
  groupby(...).transform("median")  → 원본 길이로 펼친 결과
                                       (fillna에 그대로 넣을 수 있음)
  ```

**Ping 13 시연 포인트** (5분):

## 자주 발생하는 기술 이슈와 대응

| 증상 | 원인 | 해결 |
|---|---|---|
| URL 로딩 실패 | 방화벽, DNS | 노트북의 폴백 합성 데이터 사용; 실제 수치는 다름을 명시 |
| `pd.get_dummies` 후 메모리 폭발 | 범주가 매우 많은 컬럼이 섞임 | `Neighborhood`만 28개 카테고리. 정상 작동. |
| `groupby` 결과의 `Series` vs `DataFrame` 혼동 | `[col]` 대괄호 한 쌍 vs 두 쌍 차이 | `df.groupby("X")["Y"]`는 Series, `df.groupby("X")[["Y"]]`는 DataFrame |
| `transform` vs `apply` 혼동 | 둘 다 그룹에 함수 적용 | `transform`은 원본 길이 보존, `apply`는 임의 길이 가능 |
| `fillna` 후에도 결측이 남음 | dtype 불일치 (예: float 컬럼에 문자열 채우기) | 컬럼별 dtype 먼저 확인 |

## 평가 지침

**워크북 점검 시 가중치**:
- 1-2장 개념 빈칸 (15%): 도구 이름 정확성
- 3-4장 개념 빈칸 (30%): *왜도와 결측의 두 종류*는 반드시 정확히 답할 것. 이해 못 하면 부스팅 강의에서 곤란.
- 5-6장 개념 빈칸 (25%): 원-핫과 상관계수 해석
- 7-8장 개념 빈칸 (20%): groupby 메서드 차이 + 특성공학 동기
- 코드 빈칸 전체 (10%): 보너스. 정확한 메서드명을 외우는 것이 핵심.

**연습문제 10선의 활용**:
- 과제로 부과: 5번까지는 워밍업, 6-10번은 응용.
- 8번(차고 유무 차이)과 10번(비율 변수)은 *직관과 다른 결과*가 나올 수 있어 추가 토론용으로 좋음.
