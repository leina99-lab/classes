    myInsert x [] = [x] := rfl

theorem myInsert_cons_le (x h : Nat) (t : List Nat) (hle : x ≤ h) :

  unfold myInsert
  rw [if_pos hle]      -- if 조건이 참이므로 then 분기 선택

  rw [if_neg hgt]      -- if 조건이 거짓이므로 else 분기 선택

## Q2 정답

## Q3 정답

> 귀납 가설: k(k+1)/2
>
> 목표: (k+1)(k+2)/2
>
> (k+1) × ( **k**/2 + 1 ) = (k+1) × **(k+2)**/2 = **(k+1)(k+2)**/2  ✓

## Q4 정답

> **기저** (n=1): 2^**1** = **2** > **1**  ✓
>
> **귀납 가설**: 2^k > **k**
>
> 2^(k+1) = **2** × 2^k = 2^k + 2^k > **k** + **k** ≥ k+1  ✓

## Q15 정답

> 역방향 `rw [← lemma]`는 목표에서 **우변 형태를 발견해서 좌변 형태로 되돌릴 때** 사용한다.
>
> 예: `a*c + b*c` 형태를 `(a+b)*c`로 묶으려면 `rw [← Nat.add_mul]`을 쓴다.
> `Nat.add_mul`의 좌변은 `(a+b)*c`, 우변은 `a*c + b*c`이므로, 역방향은 우변→좌변, 즉 묶는 방향이다.
