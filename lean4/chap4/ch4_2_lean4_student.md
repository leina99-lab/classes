## 1. 들어가며

§4.2 강의에서는 **정수의 표현**(representation of integers)과 **진법 변환 알고리즘**을 배웠다. 우리가 평소 쓰는 10진법뿐만 아니라 2진법, 8진법, 16진법 등 다양한 진법으로 같은 수를 표현할 수 있다. 진법 사이의 변환과 그 효율적인 알고리즘이 이 절의 중심 주제이다.

Lean 4에서는 이를 다루기 위해 **`Nat.digits`**라는 표준 API가 Mathlib에 들어 있다. 본 자료는 이 API의 사용법을 익히고, 모듈러 멱승(modular exponentiation) 알고리즘까지 다룬다.

본 자료를 다 따라가고 나면 다음을 할 수 있게 된다.

1. Mathlib의 `Nat.digits` 함수로 자연수를 임의의 진법으로 변환할 수 있다.
2. `Nat.ofDigits`로 자릿수 리스트를 다시 원래 자연수로 합성할 수 있다.
3. 2진법·8진법·16진법으로의 변환 예제를 다룰 수 있다.
4. 모듈러 멱승(`a^n mod m`)을 효율적으로 계산하는 알고리즘을 Lean 4로 직접 구현할 수 있다.

---

## 2. `Nat.digits`로 진법 변환하기

**정의** Mathlib의 `Nat.digits b n`은 자연수 `n`을 `b`진법으로 표현했을 때의 자릿수 리스트를 돌려준다. 단, **낮은 자리부터** 순서로 적힌다.

예를 들어, 십진수 1234는 다음과 같이 표현된다.

```
1234 = 1·1000 + 2·100 + 3·10 + 4·1
```

낮은 자리부터 4, 3, 2, 1. 따라서 `Nat.digits 10 1234 = [4, 3, 2, 1]`이다.

```lean
import Mathlib

example : Nat.digits 10 1234 = [4, 3, 2, 1] := by decide
```

이 한 줄이 위 사실을 컴퓨터가 직접 계산으로 검증한 것이다.

낮은 자리부터 적는 이유는 알고리즘의 자연스러움 때문이다. 어떤 수를 진법으로 변환할 때 가장 먼저 알게 되는 자릿수는 가장 낮은 자리(즉 `n mod b`)이기 때문이다. 종이에 적을 때는 보통 높은 자리부터 적으니, 시각적으로는 리스트를 거꾸로 읽으면 된다.

**2진법 시연** 13을 2진법으로 표현하면 `1101₂`이다. 이는 8 + 4 + 1 = 13이다.

```
13 = 1·8 + 1·4 + 0·2 + 1·1 = 1101₂
```

낮은 자리부터 1, 0, 1, 1. 따라서 `Nat.digits 2 13 = [1, 0, 1, 1]`.

```lean
example : Nat.digits 2 13 = [1, 0, 1, 1] := by decide
```

**16진법 시연** 255 = 16² − 1 = FF₁₆. 두 자리 모두 15.

```lean
example : Nat.digits 16 255 = [15, 15] := by decide
```

Lean 4에서는 16진법의 자릿수가 0~15까지의 **자연수**로 표현된다. 종이의 `F`(15에 해당)는 그저 `15`로 적힌다.

**8진법 시연** 64 = 8² = 100₈.

```lean
example : Nat.digits 8 64 = [0, 0, 1] := by decide
```

낮은 자리부터 0, 0, 1. 종이의 `100₈`을 거꾸로 읽으면 정확히 이 리스트이다.

## 3. 자릿수에서 원래 수 복원하기 - `Nat.ofDigits`

`Nat.digits`의 역연산이 `Nat.ofDigits`이다. 자릿수 리스트와 진법을 받아 원래 자연수를 돌려준다.

**핵심 정리** Mathlib의 `Nat.ofDigits_digits`:

```
Nat.ofDigits_digits : ∀ (b n : Nat), Nat.ofDigits b (Nat.digits b n) = n
```

말로 풀면 "어떤 수를 진법으로 분해했다가 다시 합성하면 원래 수가 된다". 가분 → 복원이 항상 일관됨을 보장한다.

```lean
theorem digits_round_trip (n : Nat) :
    Nat.ofDigits 10 (Nat.digits 10 n) = n :=
  Nat.ofDigits_digits 10 n
```

본 정리는 인수 두 개(`10`, `n`)만 넘기면 끝이다.

**시연** 1234의 자릿수 리스트를 다시 합치면 1234.

```lean
example : Nat.ofDigits 10 [4, 3, 2, 1] = 1234 := by decide
```

내부적으로 `Nat.ofDigits 10 [4, 3, 2, 1]`은 다음과 같이 계산된다.

```
4 + 10·(3 + 10·(2 + 10·(1 + 10·0)))
= 4 + 10·(3 + 10·(2 + 10·1))
= 4 + 10·(3 + 10·12)
= 4 + 10·123
= 4 + 1230
= 1234.
```

낮은 자리부터 끄집어내어 진법의 거듭제곱과 곱해 누적한다. 이것이 진법 합성의 본질이다.

---

## 4. 자릿수의 개수

자릿수의 개수는 `(Nat.digits b n).length`로 얻는다.

**시연 모음**

```lean
example : (Nat.digits 10 1234).length = 4 := by decide
example : (Nat.digits 10 9).length    = 1 := by decide
example : (Nat.digits 10 10).length   = 2 := by decide
example : (Nat.digits 10 99).length   = 2 := by decide
example : (Nat.digits 10 100).length  = 3 := by decide
```

자릿수의 개수가 진법의 거듭제곱과 깔끔하게 대응한다. 10⁰ ≤ n < 10¹이면 자릿수는 1. 10¹ ≤ n < 10²이면 자릿수는 2. 일반적으로 10^(d−1) ≤ n < 10^d이면 자릿수는 d.

이 사실을 일반적으로 형식화한 정리도 Mathlib에 있다(예: `Nat.size_le`, `Nat.size_digits`). 본 자료에서는 직접 호출하지 않지만, 학습자가 더 깊이 들어가고 싶다면 검색해 볼 만하다.

## 5. 진법 변환 종합 예제

**예제 1.** 25를 2진법으로.

```
25 = 16 + 8 + 1 = 1·16 + 1·8 + 0·4 + 0·2 + 1·1 = 11001₂
```

낮은 자리부터 1, 0, 0, 1, 1.

```lean
example : Nat.digits 2 25 = [1, 0, 0, 1, 1] := by decide
```

**예제 2.** 100을 2진법으로.

```
100 = 64 + 32 + 4 = 1100100₂
```

낮은 자리부터 0, 0, 1, 0, 0, 1, 1.

```lean
example : Nat.digits 2 100 = [0, 0, 1, 0, 0, 1, 1] := by decide
```

**예제 3.** 4095를 16진법으로. 4095 = 16³ − 1 = FFF₁₆.

```lean
example : Nat.digits 16 4095 = [15, 15, 15] := by decide
```

**예제 4.** 16진수 A2C₁₆을 10진수로.

종이의 A2C₁₆은 `A`(10) `2` `C`(12)인 세 자리. 낮은 자리부터의 리스트는 [12, 2, 10].

```
A2C₁₆ = 10·16² + 2·16 + 12 = 2560 + 32 + 12 = 2604₁₀
```

```lean
example : Nat.ofDigits 16 [12, 2, 10] = 2604 := by decide
```

## 6. 모듈러 멱승 (1) - 작은 수의 직접 계산

§4.2 강의의 또 하나의 기둥 주제는 **모듈러 멱승**이다. 즉 `a^n mod m`을 효율적으로 계산하는 알고리즘이다.

Lean 4에서는 작은 수의 경우 `decide`가 직접 계산으로 모듈러 멱승의 값을 판정해 준다.

**시연 1.** 3^13 mod 7 = ?

종이로 계산하면 3¹³ = 1594323. 1594323 / 7 = 227760 나머지 3. 따라서 3¹³ mod 7 = 3.

```lean
example : 3 ^ 13 % 7 = 3 := by decide
```

`decide`가 이를 한 번에 판정한다.

**시연 2.** 페르마 소정리의 사례. p가 소수이고 `gcd(a, p) = 1`이면 `a^(p-1) ≡ 1 (mod p)`이다.

11은 소수이고 2와 11은 서로소이다. 그러므로 `2^10 ≡ 1 (mod 11)`이어야 한다.

```lean
example : 2 ^ 10 % 11 = 1 := by decide
```

`decide`로 검증된다. 종이로는 2¹⁰ = 1024 = 93·11 + 1이므로 나머지 1. 정확히 페르마 소정리.

**시연 3.** 더 큰 멱승. 7^222 mod 11 = ?

페르마 소정리에 의해 7^10 ≡ 1 (mod 11)이므로

```
7^222 = 7^(22·10 + 2) = (7^10)^22 · 7^2 ≡ 1^22 · 49 = 49 ≡ 5 (mod 11)
```

```lean
example : 7 ^ 222 % 11 = 5 := by decide
```

`decide`가 작동한다. 다만 멱승의 지수가 매우 클 경우 `decide`는 시간·메모리가 폭주할 수 있으므로, 그 경우에는 `native_decide`(컴파일된 코드로 평가)를 쓰는 편이 안전하다.

## 7. 모듈러 멱승 (2) - 빠른 알고리즘 직접 구현

§4.2 강의에서 본 **빠른 멱승**(fast exponentiation, 또는 반복 제곱법) 알고리즘을 Lean 4로 구현해 본다.

**알고리즘 개요** `a^n mod m`을 계산할 때, `n`을 2진법으로 표현하고 비트별로 처리한다. 예를 들어 `a^13 = a^(1101₂) = a^8 · a^4 · a^1`. 즉 `n`이 짝수이면 `(a^(n/2))^2`로 줄이고, 홀수이면 `a · a^(n-1)`로 줄인다. 매 단계 모듈러 연산을 함께 처리한다.

```lean
def fastModPow : Nat → Nat → Nat → Nat
  | _,    0,        _ => 1
  | base, exp + 1,  m =>
      if (exp + 1) % 2 = 0 then
        let half := fastModPow base ((exp + 1) / 2) m
        (half * half) % m
      else
        (base * fastModPow base exp m) % m
termination_by _ exp _ => exp
```

세 가지 새 요소이다.

**패턴 매칭으로 정의** `def fastModPow : Nat → Nat → Nat → Nat`은 세 자연수 인수를 받아 자연수를 돌려주는 함수의 선언이다. `|`로 시작하는 줄들이 **패턴 매칭** 가지이다.

첫 가지 `| _, 0, _ => 1`은 "어떤 `base`, 지수가 `0`, 어떤 `m`이면 답은 `1`". 종이의 "어떤 수의 0제곱은 1"을 옮긴 것이다. `_`(언더스코어)는 "이 자리의 값은 안 본다"는 표시.

둘째 가지 `| base, exp + 1, m =>`은 "둘째 인수가 `exp + 1` 형태, 즉 양수"인 경우. 이 가지의 안에서 `exp`라는 새 변수는 "지수에서 1을 뺀 값"을 가리킨다. 이 패턴이 본 코드의 핵심 트릭이다. 종료성을 자동으로 보장한다(자세히는 코드 설명 자료).

**짝수·홀수 분기** `if (exp + 1) % 2 = 0 then ... else ...`. 짝수이면 반으로 나누어 한 단계, 홀수이면 1을 빼고 한 단계. 두 분기 모두 결국 더 작은 지수에 대한 재귀 호출로 줄어든다.

**`termination_by`** 함수가 무한 재귀에 빠지지 않음을 Lean 4에 알리는 구문. `_ exp _ => exp`는 "세 인수 중 둘째 인수 `exp`가 매 호출마다 줄어든다"는 선언이다. 이 한 줄로 Lean 4가 자동으로 종료성을 검증한다.

**시연** 위에서 본 결과를 `fastModPow`로 검증.

```lean
example : fastModPow 3 13 7 = 3 := by native_decide
example : fastModPow 2 10 11 = 1 := by native_decide
example : fastModPow 7 222 11 = 5 := by native_decide
```

여기서 `decide` 대신 `native_decide`를 쓴다는 점이 중요하다. `decide`는 Lean 4의 커널이 정의를 한 단계씩 풀어 가며 계산하는데, 큰 수의 재귀에서는 시간이 너무 오래 걸리거나 막힐 수 있다. `native_decide`는 정의를 네이티브 코드로 컴파일한 후 평가하므로 훨씬 빠르고 안전하다.

본 자료의 다른 곳에서는 `decide`만으로 충분했지만, 사용자 정의 재귀 함수에 대한 큰 수의 검증에는 `native_decide`가 표준 선택이다.

## 8. 마무리 - 본 자료의 패턴 정리

본 자료에서 익힌 핵심 패턴 네 가지.

**패턴 1. `Nat.digits`로 진법 변환**

```lean
example : Nat.digits b n = [<자릿수 리스트, 낮은 자리부터>] := by decide
```

**패턴 2. `Nat.ofDigits`로 복원**

```lean
example : Nat.ofDigits b [<자릿수 리스트>] = <원래 수> := by decide
```

**패턴 3. 모듈러 멱승 작은 수**

```lean
example : a ^ n % m = <답> := by decide
```

작은 수면 `decide`, 클 수도 있으면 `native_decide`.

**패턴 4. 사용자 정의 재귀 함수**

```lean
def myFunc : <타입> → <타입>
  | <기저 패턴> => <기저 값>
  | <재귀 패턴 (예: x + 1)> => <재귀 호출>
termination_by <어느 인수가 줄어드는가>
```

기저 패턴이 첫 가지에서 잡히고, 재귀 패턴이 둘째 가지에서 잡히며, `termination_by`로 종료성을 명시한다.

본 자료를 따라치면, Mathlib의 `Nat.digits`/`Nat.ofDigits`/`Nat.ofDigits_digits` API, 모듈러 멱승의 `%` 연산자 사용, 그리고 사용자 정의 재귀 함수의 기초 문법에 익숙해진다.
