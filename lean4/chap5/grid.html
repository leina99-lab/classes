두 더미 게임을 처음부터 이해하기

상태 (a,b), 가능한 이동, N-위치와 P-위치, 그리고 왜 대칭 위치 (a,a)가 지는 위치인지 시각화한다.

1. 이 게임은 무엇인가

이 게임은 탁자 위에 물건 더미가 두 개 놓여 있는 게임이다. 왼쪽 더미에 a개, 오른쪽 더미에 b개가 있으면 현재 상태를 (a,b)라고 쓴다.

상태 예를 들어 (5,3)은 왼쪽 더미에 5개, 오른쪽 더미에 3개가 있다는 뜻이다.
한 번의 이동 자기 차례에는 더미 하나만 고른다. 그리고 그 더미에서 1개 이상을 제거한다. 즉 (a,b) → (a',b) 또는 (a,b) → (a,b')로 이동한다. 여기서 0 ≤ a' < a, 0 ≤ b' < b이다.
불가능한 이동 두 더미를 동시에 줄일 수 없다. 더미를 늘릴 수도 없다. 아무것도 제거하지 않는 것도 이동이 아니다.
끝 상태 (0,0)에서는 더 이상 움직일 수 없다. 자기 차례에 (0,0)을 받은 사람은 진다. 그래서 상대에게 (0,0)을 넘기면 이긴다.
가능한 이동 예 (5,3) → (2,3)
왼쪽 더미만 줄였다.
가능한 이동 예 (5,3) → (5,0)
오른쪽 더미를 모두 제거했다.
불가능한 이동 예 (5,3) → (2,1)
두 더미를 동시에 줄였으므로 안 된다.

2. 격자판으로 보는 게임 상태

P-위치: 받은 사람이 불리한 위치 N-위치: 차례인 사람이 이길 수 있는 위치 선택한 상태에서 갈 수 있는 위치 이기는 이동 거울 응수

3. 선택한 상태 설명

결론

이 게임에서는 대각선 위치 (a,a)가 전부 P-위치이다. 대각선 밖의 위치 (a,b), a ≠ b는 전부 N-위치이다.

비대칭이면 큰 더미를 작은 더미 크기까지 줄여서 바로 대칭 위치를 만들 수 있다. 대칭이면 어떤 이동을 해도 비대칭이 되고, 상대가 다시 대칭을 만들 수 있다.

4. N-위치와 P-위치는 무슨 뜻인가

N-위치 Next player winning position이다. 즉 지금 차례인 사람이 잘 두면 이기는 위치이다.
P-위치 Previous player winning position이다. 즉 이전 사람이 좋은 위치를 넘겨준 상태이다. 지금 차례인 사람은 상대가 실수하지 않으면 진다.
끝 상태 (0,0)에서는 움직일 수 없으므로 P-위치이다. 받은 사람이 진다.
(0,b), b > 0은 N-위치이다.
오른쪽 더미를 전부 제거해서 (0,0)을 상대에게 넘길 수 있기 때문이다.
(a,b), a ≠ b는 N-위치이다.
큰 더미를 작은 더미와 같게 만들 수 있다. 예를 들어 (7,3) → (3,3)이다. 이렇게 상대에게 P-위치를 넘긴다.
(a,a)는 P-위치이다.
한쪽을 줄이면 대칭이 깨진다. 그러면 상대가 다른 쪽을 똑같이 줄여 대칭을 복구한다. 이것이 거울 전략이다.

5. 실제 게임 흐름 예시

예시 A: 시작이 (5,2)이면 첫 사람이 이긴다

왜냐하면 첫 사람이 바로 큰 더미를 줄여 대칭 위치를 만들 수 있기 때문이다.

(5,2) → (2,2)

이제 상대가 어떤 한쪽을 줄여도, 첫 사람은 다른 쪽을 똑같이 줄여 다시 대칭을 만든다.

예시 B: 시작이 (3,3)이면 첫 사람이 진다

첫 사람이 한쪽을 줄일 수밖에 없다. 예를 들어 다음처럼 두었다고 하자.

(3,3) → (1,3)

그러면 두 번째 사람은 다른 쪽도 1로 줄인다.

(1,3) → (1,1)

이제 다시 대칭이다. 첫 사람이 다시 한쪽을 줄이면 두 번째 사람이 또 거울처럼 따라 한다. 결국 첫 사람이 (0,0)을 받게 된다.

예시 C: 시작이 (n,n)이면 왜 두 번째 사람이 이기는가

(n,n)은 대칭 위치이다. 첫 번째 사람은 반드시 한쪽 더미만 줄여야 하므로 대칭을 깨뜨릴 수밖에 없다.

예를 들어 첫 번째 사람이 (n,n) → (c,n)으로 두면, 두 번째 사람은 (c,n) → (c,c)로 둔다.

즉 두 번째 사람은 매번 대칭을 복구한다. 이 전략을 계속 쓰면 마지막에는 두 번째 사람이 (0,0)을 첫 번째 사람에게 넘긴다.

6. 한 줄 정리

이 게임은 두 더미 중 하나만 줄이는 게임이다. 대칭 위치 (a,a)를 받은 사람은 상대의 거울 전략 때문에 불리하다. 그래서 P-위치는 정확히 (a,a)이고, 비대칭 위치는 큰 더미를 줄여 대칭으로 만들 수 있으므로 N-위치이다.

P = {(a,a) : a ≥ 0}

N = {(a,b) : a ≠ b}

격자판에서 칸을 클릭하면 가능한 이동과 이기는 이동 또는 거울 응수를 확인할 수 있다.
