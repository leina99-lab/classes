## 슬라이드 8 -- [Lean 4] 집합 기초 [0:12~0:17]

> "Lean 4에서 집합은 술어이다. Set Nat은 Nat에서 Prop으로의 함수와 같다."

[TIP -- 라이브 데모]

```lean
-- 터미널에서 직접 실행
#eval ({1, 3, 5, 7, 9} : Finset Nat)
-- 결과: {1, 3, 5, 7, 9}

-- 순서 바꿔도 같은지?
example : ({1, 3, 5} : Finset Nat) = {3, 5, 1} := by decide
-- 증명 완료!
```

> "decide는 유한 집합의 같음을 컴퓨터가 직접 확인하는 전술이다. 일일이 원소를 비교한다."

### 추가 연습 빈칸 정답

```lean
-- 4가 MyEven의 원소인지 확인
def MyEven : Set Nat := {x | x % 2 = 0}
example : 4 ∈ MyEven := by
  simp [MyEven]    -- ← 정답
```

**설명**: `simp [MyEven]`은 두 단계로 작동한다.
1. `MyEven`의 정의를 펼친다: 목표가 `4 % 2 = 0`으로 변환.
2. `4 % 2 = 0`은 계산으로 참이므로 자동 해결.

[WARNING] `decide`는 `Set`에는 작동하지 않는다. `Set`은 술어이므로 일반적으로 결정 불가능하다. `Finset`에만 `decide`를 사용한다.

## 슬라이드 12 -- [Lean 4] 부분집합 증명 [0:25~0:30]

[TIP -- 라이브 데모: 반드시 InfoView를 보여준다]

```lean
-- 공집합이 모든 집합의 부분집합
example (A : Set Nat) : (∅ : Set Nat) ⊆ A := by
  -- InfoView 상태:
  -- 목표: ∅ ⊆ A
  intro x hx
  -- InfoView 상태:
  -- x : Nat
  -- hx : x ∈ ∅    ← 이것은 False!
  -- 목표: x ∈ A
  exact absurd hx (Set.not_mem_empty x)
  -- 증명 완료
```

> "intro x hx 후 InfoView를 보라. hx가 'x ∈ ∅'이다. 공집합에 원소가 있다는 것은 거짓이다. absurd로 모순을 유도하면 무엇이든 증명 가능하다."

```lean
-- {n | n > 5} ⊆ {n | n > 3}
example : {n : Nat | n > 5} ⊆ {n : Nat | n > 3} := by
  intro x hx     -- hx : x > 5
  -- InfoView: x : Nat, hx : x > 5 ⊢ x > 3
  omega           -- 자동 해결
```

> "omega는 자연수/정수의 선형 부등식 전문가이다. 'x > 5이면 x > 3'은 omega에게 아주 쉬운 문제이다."

### 추가 연습 빈칸 정답

```lean
example : {n : Nat | n > 10} ⊆ {n : Nat | n > 5} := by
  intro x hx
  omega            -- ← 정답
```

## 슬라이드 24 -- [Lean 4] 집합 연산 [0:55~1:00]

[TIP -- 라이브 데모]

```lean
-- 유한 집합 연산: decide로 자동
example : ({1,3,5} : Finset Nat) ∪ {1,2,3} = {1,2,3,5} := by decide
example : ({1,3,5} : Finset Nat) ∩ {1,2,3} = {1,3} := by decide
example : ({1,3,5} : Finset Nat) \ {1,2,3} = {5} := by decide
```

> "유한 집합은 decide 한 방이다. 하지만 일반 집합(Set)은 원소별 증명이 필요하다."

```lean
-- 합집합의 교환법칙 (Set 버전)
example (A B : Set Nat) : A ∪ B = B ∪ A := by
  ext x
  -- InfoView: x : Nat ⊢ x ∈ A ∪ B ↔ x ∈ B ∪ A
  simp [Set.mem_union, or_comm]
  -- or_comm : p ∨ q ↔ q ∨ p  (1장의 논리 교환법칙!)
```

> "ext가 핵심이다. 집합의 같음을 '임의의 x에 대해 양쪽 소속이 동치'로 변환한다. 그 다음은 1장에서 배운 논리 법칙으로 마무리한다."

### 추가 연습 정답

```lean
-- 교집합 교환법칙
example (A B : Set Nat) : A ∩ B = B ∩ A := by
  ext x
  simp [Set.mem_inter_iff, and_comm]    -- ← 정답
```

**설명**: `Set.mem_inter_iff`가 `x ∈ A ∩ B`를 `x ∈ A ∧ x ∈ B`로 풀고, `and_comm`이 `P ∧ Q ↔ Q ∧ P`를 적용한다.

## 슬라이드 25 -- 집합의 항등 관계 (표 1) [1:00~1:03]

> "표 1이다. 1장에서 배운 논리적 동치의 집합 버전이다."

> "이름을 외우기보다 패턴을 파악하라. AND를 교집합, OR를 합집합, NOT을 여집합으로 바꾸면 된다."

[TIP] 이 표를 칠판에 두 열로 나란히 쓰면 효과적이다:

| 논리 (1장) | 집합 (2장) |
|-----------|-----------|
| p ∧ True ≡ p | A ∩ U = A |
| p ∨ False ≡ p | A ∪ ∅ = A |
| ¬(p ∧ q) ≡ ¬p ∨ ¬q | (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ |

> "1장과 2장은 같은 법칙의 두 가지 얼굴이다."

## 슬라이드 26~27 -- 드 모르간 + Lean [1:03~1:08]

> "드 모르간 법칙 증명. 방법 1은 원소별 추적. 방법 2는 조건제시법으로 논리식 변환."

> "Lean에서는 ext로 원소별 증명을 시작하고 simp가 나머지를 처리한다."

[TIP -- 라이브 데모: 드 모르간 제1법칙]

```lean
example (A B : Set Nat) :
    (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ := by
  ext x
  -- InfoView: x : Nat ⊢ x ∈ (A ∩ B)ᶜ ↔ x ∈ Aᶜ ∪ Bᶜ
  simp [Set.mem_compl_iff, Set.mem_union,
        Set.mem_inter_iff, not_and_or]
  -- not_and_or : ¬(P ∧ Q) ↔ ¬P ∨ ¬Q  (논리의 드 모르간!)
```

> "핵심을 보라. 집합의 드 모르간을 증명하는 데 논리의 드 모르간(`not_and_or`)을 그대로 사용한다. 1장과 2장이 연결되는 순간이다."

### 1:1 매칭 표 (슬라이드에 표시)

| 수학 증명 단계 | Lean 코드 | 사용된 정리 |
|---------------|-----------|------------|
| 원소별로 보자 | `ext x` | 외연성(extensionality) |
| x ∈ (A ∩ B)ᶜ 풀기 | `Set.mem_compl_iff` | 여집합 정의 |
| x ∈ A ∩ B 풀기 | `Set.mem_inter_iff` | 교집합 정의 |
| ¬(P ∧ Q) → ¬P ∨ ¬Q | `not_and_or` | 논리 드 모르간 |
| x ∈ Aᶜ ∪ Bᶜ 합치기 | `Set.mem_union` | 합집합 정의 |

### 추가 연습 정답

```lean
-- 분배 법칙
example (A B C_ : Set Nat) :
    A ∩ (B ∪ C_) = (A ∩ B) ∪ (A ∩ C_) := by
  ext x
  simp [Set.mem_inter_iff, Set.mem_union, and_or_left]  -- ← 정답
```

**설명**: `and_or_left`는 `P ∧ (Q ∨ R) ↔ (P ∧ Q) ∨ (P ∧ R)`이다. 이것이 분배법칙의 논리 버전이다.

## 슬라이드 33 -- 전술 요약

> "오늘 사용한 전술을 정리한다."

| 전술 | 용도 | 핵심 장면 |
|------|------|-----------|
| `intro x hx` | 변수/가정 도입 | 부분집합 ⊆ 증명 |
| `exact` | 증거 제시 | absurd와 함께 |
| `omega` | 선형 산술 | 부등식 자동 |
| `ext x` | 집합 같음 | A = B 증명 |
| `simp [...]` | 자동 단순화 | 집합 연산 + 논리 법칙 |
| `decide` | 유한 결정 | Finset 같음 |
| `absurd` | 모순 유도 | 공집합 ⊆ A |
| `#eval` | 계산 확인 | 크기, 멱집합 |

> "가장 중요한 것을 하나만 고르면 **부분집합 증명 패턴**이다. intro로 원소를 잡고, 가정에서 결론으로. 이 패턴은 이산수학 전체에서 반복된다."

### 문제 1: 부분집합

```lean
example : {n : Nat | n > 20} ⊆ {n : Nat | n > 10} := by
  intro x hx      -- hx : x > 20
  omega            -- 20 < x → 10 < x
```

### 문제 2: 합집합의 결합법칙

```lean
example (A B C : Set Nat) :
    A ∪ (B ∪ C) = (A ∪ B) ∪ C := by
  ext x
  simp [Set.mem_union, or_assoc]
  -- or_assoc : (P ∨ Q) ∨ R ↔ P ∨ (Q ∨ R)
```

### 문제 3: 흡수법칙

```lean
example (A B : Set Nat) :
    A ∪ (A ∩ B) = A := by
  ext x
  simp [Set.mem_union, Set.mem_inter_iff]
  intro ha _
  exact ha
```

### 도전 1: 흡수법칙 (교집합 버전)

```lean
example (A B : Set Nat) :
    A ∩ (A ∪ B) = A := by
  ext x
  simp [Set.mem_inter_iff, Set.mem_union]
  intro ha
  left
  exact ha
```

### 도전 2: 차집합과 교집합

```lean
example (A B : Set Nat) :
    (A \ B) ∪ (A ∩ B) = A := by
  ext x
  simp [Set.mem_union, Set.mem_diff, Set.mem_inter_iff]
  tauto
```

# Lean 4 코드에서 자주 나오는 정리 이름 (교수자 참고)

| 정리 이름 | 내용 | 집합 대응 |
|-----------|------|-----------|
| `or_comm` | P ∨ Q ↔ Q ∨ P | ∪ 교환 |
| `and_comm` | P ∧ Q ↔ Q ∧ P | ∩ 교환 |
| `or_assoc` | (P ∨ Q) ∨ R ↔ P ∨ (Q ∨ R) | ∪ 결합 |
| `and_assoc` | (P ∧ Q) ∧ R ↔ P ∧ (Q ∧ R) | ∩ 결합 |
| `not_and_or` | ¬(P ∧ Q) ↔ ¬P ∨ ¬Q | 드 모르간 1 |
| `not_or` | ¬(P ∨ Q) ↔ ¬P ∧ ¬Q | 드 모르간 2 |
| `and_or_left` | P ∧ (Q ∨ R) ↔ (P ∧ Q) ∨ (P ∧ R) | ∩ 분배 |
| `or_and_left` | P ∨ (Q ∧ R) ↔ (P ∨ Q) ∧ (P ∨ R) | ∪ 분배 |
| `Set.mem_union` | x ∈ A ∪ B ↔ x ∈ A ∨ x ∈ B | ∪ 정의 |
| `Set.mem_inter_iff` | x ∈ A ∩ B ↔ x ∈ A ∧ x ∈ B | ∩ 정의 |
| `Set.mem_compl_iff` | x ∈ Aᶜ ↔ x ∉ A | ᶜ 정의 |
| `Set.not_mem_empty` | x ∉ ∅ | ∅ 정의 |
