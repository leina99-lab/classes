# 이산수학 11장 트리 학습 자료

이 폴더는 업로드된 11장 자료의 흐름에 맞추어 학생용으로 재구성한 Markdown 학습 자료이다. 원문 문장과 원문 그림을 복제하지 않고, 핵심 개념을 설명식 예제와 새 그림으로 다시 구성했다.

## 파일 구성

| 파일 | 내용 | 핵심 역량 |
|---|---|---|
| `11_1_트리_소개.md` | 트리, 숲, 루트 트리, m-항 트리, 기본 성질 | 트리 판정과 용어 정리 |
| `11_2_트리의_응용.md` | 이진 탐색 트리, 결정 트리, 접두어 코드, 허프만 코드, 게임 트리 | 트리를 실제 문제 모델로 사용하는 능력 |
| `11_3_트리_탐방.md` | 주소 체계, 전위/중위/후위 탐방, 수식 트리, 표기법 | 트리를 순서대로 읽고 계산하는 능력 |
| `11_4_신장_트리.md` | 신장 트리, 깊이 우선 탐색, 너비 우선 탐색, 백트래킹 | 그래프에서 트리를 뽑아내는 능력 |
| `11_5_최소_신장_트리.md` | 가중 그래프, 프림 알고리즘, 크루스칼 알고리즘, 안전한 간선 | 최적 네트워크를 구성하는 능력 |

## 권장 학습 순서

1. 먼저 각 파일의 학습 목표와 핵심 그림을 읽는다.
2. 정의를 외우기 전에 예제의 풀이 흐름을 따라간다.
3. 풀이에서 왜 그런 판단을 하는지 설명한 부분을 소리 내어 다시 말한다.
4. 각 절 끝의 자기 점검 문제를 풀고 답을 대조한다.
5. 알고리즘 절에서는 그림의 간선 선택 순서를 손으로 다시 그려 본다.

## 표기 약속

- 정점 수는 보통 $n$, 간선 수는 보통 $e$로 쓴다.
- 루트 트리에서 내부 정점 수는 $i$, 잎 수는 $l$로 쓴다.
- 트리의 높이는 루트에서 가장 먼 잎까지의 간선 수로 본다.
- 모든 그림은 `assets` 폴더에 있는 SVG 파일을 참조한다.
