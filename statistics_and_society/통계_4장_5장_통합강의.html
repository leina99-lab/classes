제4장 · 확률변수의 분포

본 장에서는 5장의 통계적 추론으로 직결되는 세 가지 핵심 분포를 다룬다. 연속분포의 대표인 정규분포(normal distribution)는 Z-점수, 표준오차, 신뢰구간, 가설검정의 토대가 된다. 이산분포인 이항분포(binomial)는 비율 추론과 직결되며, 큰 표본에서 정규분포로 근사된다. 마지막으로 포아송분포(Poisson)는 이항분포의 극한으로서 드문 사건을 다루는 강력한 도구이다.

4.1 정규분포 (Normal Distribution)

통계학에서 가장 흔히 마주치는 분포는 대칭적이고, 단봉(unimodal)이며, 종 모양의 곡선을 갖는다. 이 분포는 매우 빈번하게 나타나기 때문에 정규분포(normal distribution) 또는 가우스 분포(Gaussian distribution)라 불린다. SAT 점수와 미국 성인 남성의 키 등은 정규분포를 매우 잘 따른다.

정규분포의 핵심 사실
많은 변수가 거의 정규분포를 따르지만, 어떤 변수도 정확히 정규분포를 따르지는 않는다. 따라서 정규분포는 단일 문제에 완벽하지는 않으나, 다양한 문제에 매우 유용하다.

4.1.1 정규분포 모형

정규분포는 항상 대칭적이고 단봉인 종 모양 곡선을 나타낸다. 그러나 이 곡선은 두 가지 모수(parameter)에 따라 다르게 보일 수 있다.

  • 평균(μ): 곡선을 좌우로 이동시킨다.
  • 표준편차(σ): 곡선을 늘리거나 좁힌다.

정규분포가 평균 $\mu$와 표준편차 $\sigma$를 가질 때, 이를 $N(\mu, \sigma)$로 표기한다.

표준정규분포(Standard Normal Distribution)
평균 $\mu = 0$이고 표준편차 $\sigma = 1$인 정규분포를 표준정규분포라 한다.

4.1.2 Z-점수를 이용한 표준화

데이터를 표준화된 척도로 변환하면 비교가 더 합리적이 된다.

정의

Z-점수(Z-score)는 관측값이 평균으로부터 몇 표준편차 떨어져 있는지를 나타낸다.

$$Z = \frac{x - \mu}{\sigma}$$
  • $Z > 0$: 평균보다 위
  • $Z < 0$: 평균보다 아래
  • $Z = 0$: 평균과 같음
Example 4.2
SAT와 ACT 점수 비교
[문제] SAT의 평균은 1100, 표준편차는 200이다. ACT의 평균은 21, 표준편차는 6이다.
Ann은 SAT에서 1300점을, Tom은 ACT에서 24점을 받았다. 누가 상대적으로 더 잘했는가?
# === 도우미 함수 === def z_score(x, mu, sigma): return (x - mu) / sigma # === 본 코드 === # 두 학생의 Z-점수 비교 ann_z = z_score(1300, 1100, 200) # SAT: 평균 1100, 표준편차 200 tom_z = z_score(24, 21, 6) # ACT: 평균 21, 표준편차 6 print(f"Ann의 Z-점수 (SAT 1300점): {ann_z}") print(f"Tom의 Z-점수 (ACT 24점): {tom_z}") print() print(f"→ Ann은 평균보다 {ann_z} 표준편차 위") print(f"→ Tom은 평균보다 {tom_z} 표준편차 위") print(f"→ {'Ann' if ann_z > tom_z else 'Tom'}이 상대적으로 더 잘했다.")
해석 및 결론 보기

Ann의 Z-점수는 1.0, Tom의 Z-점수는 0.5이다. 즉 Ann은 평균보다 1 표준편차 위에 있고, Tom은 0.5 표준편차 위에 있다. 따라서 Ann이 자신의 시험 응시자 집단 안에서 더 우수한 위치에 있다고 결론지을 수 있다.

이처럼 Z-점수는 서로 다른 척도의 점수를 공정하게 비교할 수 있게 해 주는 표준화 도구이다.

4.1.3 꼬리 영역과 정규분포 확률

SAT 점수는 $N(\mu = 1100, \sigma = 200)$으로 잘 근사된다. 정규분포 확률 계산은 통계 소프트웨어를 사용하면 매우 간단하다.

Example 4.7
최소 1190점을 받을 확률
[문제] Shannon이 SAT에서 최소 1190점을 받을 확률은 얼마인가?
# === 도우미 함수 === from scipy import stats def z_score(x, mu, sigma): return (x - mu) / sigma def normal_right(z): return 1 - stats.norm.cdf(z) # === 본 코드 === # 1단계: Z-점수 계산 mu, sigma = 1100, 200 x = 1190 z = z_score(x, mu, sigma) # 2단계: 오른쪽 꼬리 영역 (1190점 이상) prob_right = normal_right(z) print(f"x = {x}, μ = {mu}, σ = {sigma}") print(f"Z = ({x} - {mu})/{sigma} = {z}") print(f"P(X ≥ {x}) = P(Z ≥ {z}) = {prob_right:.4f}") print(f"→ 약 {prob_right*100:.2f}%의 확률이다.")
해설 보기

1단계: $Z = (1190 - 1100)/200 = 0.45$

2단계: 통계 소프트웨어로 $Z = 0.45$ 이상의 영역을 구하면 약 0.3264이다.

결론: Shannon이 1190점 이상을 받을 확률은 약 32.64%이다.

Example 4.13
백분위에서 관측값 찾기 — Erik의 키
[문제] 미국 성인 남성의 키가 $N(70.0, 3.3)$(인치)을 따른다고 하자. Erik의 키는 40번째 백분위에 있다. Erik의 키는 얼마인가?
# === 도우미 함수 === from scipy import stats def percentile_to_z(p): return stats.norm.ppf(p) # === 본 코드 === # 1단계: 40번째 백분위에 해당하는 Z-점수 percentile = 0.40 z = percentile_to_z(percentile) # 2단계: x = μ + Z·σ mu, sigma = 70.0, 3.3 x = mu + z * sigma print(f"40번째 백분위의 Z-점수: {z:.3f}") print(f"Erik의 키: {x:.2f} 인치") print(f"(약 {int(x//12)}피트 {x%12:.1f}인치)")
풀이 보기

40번째 백분위의 Z-점수는 약 $-0.25$이다. 따라서

$$x = \mu + Z\sigma = 70 + (-0.25)(3.3) \approx 69.18 \text{ 인치}$$

Erik의 키는 약 69.18인치(약 5'9")이다.

다양한 백분위에 해당하는 점수를 빠르게 확인해 보자.

4.1.4 68-95-99.7 규칙

정규분포에서 평균을 중심으로 1, 2, 3 표준편차 이내에 들어갈 확률에 대한 유용한 규칙이 있다.

범위확률
$\mu \pm 1\sigma$약 68%
$\mu \pm 2\sigma$약 95%
$\mu \pm 3\sigma$약 99.7%
# === 도우미 함수 === from scipy import stats def normal_left(z): return stats.norm.cdf(z) # === 본 코드 === # 68-95-99.7 규칙을 직접 검증 for k in [1, 2, 3]: prob = normal_left(k) - normal_left(-k) print(f"P(-{k} ≤ Z ≤ {k}) = {prob:.4f} ({prob*100:.2f}%)")
◈ 새로운 시각
표준화의 힘

Z-점수 변환은 단순해 보이나, 그 위력은 막대하다. 서로 다른 척도의 데이터를 동일한 기준(표준정규분포)으로 변환함으로써 다음의 일을 할 수 있다.

  1. 서로 다른 시험 점수의 공정한 비교(SAT vs ACT)
  2. 이상치의 객관적 식별(|Z| > 2 또는 3)
  3. 확률 계산의 통일 — 모든 정규분포 문제가 표준정규분포표 하나로 해결된다.

이 개념은 후술하는 검정통계량(test statistic)의 토대가 된다. 가설검정에서 우리는 관측된 통계량을 Z-점수처럼 표준화하여 "얼마나 극단적인가"를 판단한다.

GRE 점수의 비교
[문제] Sophia는 GRE Verbal Reasoning에서 160점, Quantitative Reasoning에서 157점을 받았다. 각 섹션의 분포는 다음과 같다.
  • Verbal: 평균 151, 표준편차 7
  • Quantitative: 평균 153, 표준편차 7.67
두 분포가 정규분포에 가깝다고 가정한다. (a) Sophia의 각 섹션 Z-점수를 구하라. (b) 어느 섹션에서 상대적으로 더 잘했는가? (c) 각 섹션의 백분위는?
# === 도우미 함수 === from scipy import stats def z_score(x, mu, sigma): return (x - mu) / sigma def normal_left(z): return stats.norm.cdf(z) # === 본 코드 === # 두 섹션의 Z-점수 및 백분위 한꺼번에 계산 verbal_z = z_score(160, 151, 7) quant_z = z_score(157, 153, 7.67) verbal_pct = normal_left(verbal_z) quant_pct = normal_left(quant_z) print(f"Verbal: Z = {verbal_z:.2f}, 백분위 ≈ {verbal_pct*100:.1f}") print(f"Quantitative: Z = {quant_z:.2f}, 백분위 ≈ {quant_pct*100:.1f}") print() print(f"→ Sophia는 {'Verbal' if verbal_z > quant_z else 'Quantitative'}에서 상대적으로 더 잘했다.")
전체 풀이 보기

(a) Z-점수: $Z_{VR} = (160-151)/7 \approx 1.29$, $Z_{QR} = (157-153)/7.67 \approx 0.52$.

(b) 상대적 성과: Z-점수가 더 큰 Verbal Reasoning에서 상대적으로 더 잘했다.

(c) 백분위: Verbal은 약 90번째 백분위, Quantitative는 약 70번째 백분위이다. 즉 원점수만 비교(160 > 157)하면 잘못된 결론에 이르므로, 표준화된 비교가 필수적이다.

4.2 이항분포 (Binomial Distribution)

이항분포는 고정된 횟수의 독립 시행에서 성공의 수를 나타내는 분포이다. 비율 추론의 직접적 토대가 되는 분포이므로, 5장 통계적 추론으로 진입하기 전에 반드시 익혀 둘 필요가 있다.

정의 — 이항분포

$n$번의 독립적인 시행에서 성공 확률이 $p$일 때, 정확히 $k$번 성공할 확률은 다음과 같다.

$$P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}$$

평균, 분산, 표준편차는 다음과 같다.

$$\mu = np, \quad \sigma^2 = np(1-p), \quad \sigma = \sqrt{np(1-p)}$$

이항분포의 적용 조건 (4가지)

  1. 시행이 독립이다.
  2. 시행 횟수 $n$이 고정되어 있다.
  3. 각 시행의 결과는 성공 또는 실패로 분류된다.
  4. 성공 확률 $p$가 모든 시행에서 동일하다.
Example 4.30
8명 중 5명이 공제액을 초과하지 않을 확률
[문제] 70%의 고객이 공제액을 초과하지 않는다고 하자. 8명 중 정확히 5명이 공제액을 초과하지 않을 확률은?
# === 도우미 함수 === from scipy import stats def binom_pmf(k, n, p): return stats.binom.pmf(k, n, p) # === 본 코드 === n, k, p = 8, 5, 0.7 prob = binom_pmf(k, n, p) combo = math.comb(n, k) print(f"C({n},{k}) = {combo}") print(f"p^k × (1-p)^(n-k) = {p**k:.5f} × {(1-p)**(n-k):.5f}") print(f"P(X = {k}) = {combo} × {p**k:.5f} × {(1-p)**(n-k):.5f}") print(f" = {prob:.4f} (약 {prob*100:.2f}%)")
해석 보기

$\binom{8}{5} = 56$이고, $(0.7)^5(0.3)^3 \approx 0.00454$이므로

$$P(X=5) = 56 \times 0.00454 \approx 0.254$$

약 25.4%의 확률로 정확히 5명이 공제액을 초과하지 않는다.

🔧 직접 풀어보기 — 이항분포 탐색

$n$, $p$, $k$ 값만 바꿔 보면서 이항분포가 어떻게 변하는지 관찰해 보자.

4.2.2 이항분포의 정규근사

표본 크기가 충분히 클 때, 이항분포는 정규분포로 근사할 수 있다. 다음 두 조건을 만족하면 근사가 충분히 정확하다.

$$np \geq 10 \quad \text{이고} \quad n(1-p) \geq 10$$

이 조건이 충족되면 $\text{Binomial}(n, p) \approx N(\mu = np, \sigma = \sqrt{np(1-p)})$이다.

Example 4.38
흡연율 조사 — 정규근사
[문제] 미국 인구의 약 15%가 흡연한다. 400명을 무작위로 조사했을 때 42명 이하가 흡연자일 확률을 정규근사로 구하라.
# === 도우미 함수 === import math from scipy import stats def z_score(x, mu, sigma): return (x - mu) / sigma def normal_left(z): return stats.norm.cdf(z) def binom_cdf(k, n, p): return stats.binom.cdf(k, n, p) def binom_mean(n, p): return n * p def binom_std(n, p): return math.sqrt(n * p * (1 - p)) # === 본 코드 === n, p = 400, 0.15 k = 42 # 조건 확인 np_ = n * p nq_ = n * (1 - p) print(f"조건: np = {np_}, n(1-p) = {nq_} → 정규근사 가능: {np_ >= 10 and nq_ >= 10}") # 정규분포 모수 mu_b = binom_mean(n, p) sd_b = binom_std(n, p) # Z-점수와 근사 확률 z = z_score(k, mu_b, sd_b) approx = normal_left(z) exact = binom_cdf(k, n, p) print(f"\n정규근사: μ = {mu_b}, σ = {sd_b:.3f}") print(f"Z = ({k} - {mu_b})/{sd_b:.3f} = {z:.2f}") print(f"근사 P(X ≤ {k}) = {approx:.4f}") print(f"정확 P(X ≤ {k}) = {exact:.4f} (이항분포 직접 계산)")
해석 보기

정규근사로 얻은 0.0059와 정확한 이항분포 값 0.0054는 매우 가깝다. 따라서 $np \ge 10$, $n(1-p) \ge 10$ 조건이 만족될 때 정규근사는 실용적으로 충분하다.

이 정규근사는 곧이어 다룰 중심극한정리의 한 사례라고 볼 수 있다.

◈ 새로운 시각
이항분포의 정규근사가 작동하는 이유 — 중심극한정리

이항분포에서 성공 횟수 $X$는 $n$개의 독립적인 베르누이 확률변수의 합이다.

$$X = X_1 + X_2 + \cdots + X_n$$

여기서 각 $X_i$는 성공이면 1, 실패면 0이다. 중심극한정리(Central Limit Theorem)에 의하면 $n$이 충분히 크면 독립 확률변수들의 합은 정규분포에 가까워진다. 따라서 $n$이 클 때 $X \sim N(np, \sqrt{np(1-p)})$로 근사된다.

조건 $np \ge 10$과 $n(1-p) \ge 10$의 의미는 다음과 같다.

  • $np \ge 10$: 평균적으로 최소 10번의 성공이 예상된다.
  • $n(1-p) \ge 10$: 평균적으로 최소 10번의 실패가 예상된다.

이 조건은 분포가 양쪽 끝으로 충분히 퍼져 종 모양에 가까워지도록 보장하는 역할을 한다.

4.3 포아송분포 (Poisson Distribution)

포아송분포는 주어진 시간이나 공간에서 드문 사건이 발생하는 횟수를 모델링한다. 단위 시간당 평균 발생률을 $\lambda$로 둘 때, 발생 횟수 $X$의 분포는 다음과 같다.

$$P(X = k) = \frac{\lambda^k e^{-\lambda}}{k!}, \quad k = 0, 1, 2, \ldots$$
포아송분포의 특별한 성질

평균과 분산이 모두 $\lambda$로 같다.

$$\mu = \lambda, \qquad \sigma^2 = \lambda, \qquad \sigma = \sqrt{\lambda}$$
Example 4.51
NYC 심장마비 환자 — 정확히 2명
[문제] 뉴욕시에서 하루에 평균 4.4명이 급성 심근경색(AMI)으로 입원한다. 어떤 날 정확히 2명의 환자가 입원할 확률은?
# === 도우미 함수 === from scipy import stats def poisson_pmf(k, lam): return stats.poisson.pmf(k, lam) # === 본 코드 === lam = 4.4 k = 2 prob = poisson_pmf(k, lam) print(f"λ = {lam}, k = {k}") print(f"P(X = {k}) = ({lam}^{k} × e^(-{lam})) / {k}!") print(f" = {lam**k:.3f} × {math.exp(-lam):.4f} / {math.factorial(k)}") print(f" = {prob:.4f} (약 {prob*100:.2f}%)")

◈ 새로운 시각
포아송분포는 이항분포의 극한이다

이항분포 $B(n, p)$에서 다음 조건이 성립할 때, 분포는 포아송분포에 수렴한다.

  • $n \to \infty$ (시행 횟수가 매우 커진다)
  • $p \to 0$ (성공 확률이 매우 작아진다)
  • $np = \lambda$ (평균은 일정하게 유지된다)

NYC 심장마비 사례로 이해하기: 뉴욕시 800만 명 각각이 하루 중 심장마비를 일으킬지(성공)/아닐지(실패)를 결정하는 베르누이 시행이라고 가정해 보자. $n = 8{,}000{,}000$, $p \approx 0.00000055$이며, $np \approx 4.4$이다. 이항분포 $B(8{,}000{,}000, 0.00000055)$를 직접 계산하기는 사실상 불가능하지만, 포아송분포 $\text{Poisson}(4.4)$로 훌륭하게 근사할 수 있다.

이것이 포아송분포가 흔히 "드문 사건의 분포"(distribution of rare events)라 불리는 이유이다.

4장 종합 — 분포들의 관계 
베르누이 시행 (1회: 성공/실패)
        │
        ▼
   이항분포 B(n, p)  ← n회 시행에서의 성공 횟수
        │
        ├──→ 정규분포 N(np, √(np(1-p)))   [n이 클 때, np≥10, n(1-p)≥10]
        │
        └──→ 포아송분포 Poisson(λ)        [n→∞, p→0, np=λ 일정]
                          │
                          (드문 사건의 분포)

  3. 이항분포의 또 다른 극한이 포아송분포이다. 사건이 드물수록(작은 $p$) 포아송 근사가 유리하다.

제5장 · 통계적 추론의 기초

통계적 추론(statistical inference)은 모수 추정의 불확실성을 이해하고 정량화하는 학문이다. 본 장에서는 친숙한 주제인 표본비율을 통해 모집단비율을 추정하는 아이디어로 시작하여, 신뢰구간(confidence interval), 그리고 가설검정(hypothesis testing) 프레임워크까지 차례로 소개한다.

5.1 점추정과 표본 변동성

Pew Research와 같은 기관은 정치, 과학적 이해, 브랜드 인지도 등 많은 주제에 대한 여론을 파악하기 위해 자주 여론조사를 실시한다. 여론조사의 궁극적인 목표는 응답 표본을 사용하여 더 넓은 모집단의 의견을 추정하는 것이다.

5.1.1 점추정과 오차

어떤 여론조사에서 미국 대통령의 지지율이 45%라고 했다 하자. 우리는 45%를 전체 모집단 응답에서 나타날 지지율의 점추정값(point estimate)으로 간주한다. 이 모집단 비율을 모수(parameter)라 하며 $p$로 표기하고, 표본비율은 $\hat{p}$로 표기한다.

두 번째 여론조사를 실시하면 약간 다른 점추정값을 얻을 것이다. 이러한 표본 간 차이를 표본오차(sampling error)라 한다. 표본오차와 함께 주의해야 할 또 하나의 오차가 편향(bias)이다. 편향은 추정값이 모수를 체계적으로 과대 또는 과소 추정하도록 만들 때 발생한다.

◈ 새로운 시각
표본오차와 편향의 차이
  • 표본오차: 무작위성으로 인한 자연스러운 변동. 표본 크기를 늘리면 줄일 수 있다.
  • 편향: 체계적인 오차. 표본 크기를 늘려도 해결되지 않으며, 데이터 수집 방법 자체를 개선해야 한다.

예를 들어 전화 여론조사에서 젊은 세대가 응답하지 않는 경향이 있다면 이는 편향을 만들어낸다. 더 많은 전화를 걸어도 이 문제는 해결되지 않는다.

5.1.2 점추정의 변동성 이해

Pew Research는 태양 에너지 역할 확대를 지지하는 미국 성인의 비율을 약 $p = 0.88$로 추정한다. 만약 1000명의 미국 성인을 다시 표본추출한다면 표본비율 $\hat{p}$이 얼마나 달라질 것인가? 이 변동성을 시뮬레이션을 통해 이해할 수 있다.

Example 5.1
표본 크기와 표준오차
[문제] 만약 훨씬 작은 표본 크기 $n = 50$을 사용했다면, $\hat{p}$의 표준오차가 $n = 1000$을 사용했을 때보다 클까 작을까?
# === 도우미 함수 === import math def se_proportion(p, n): return math.sqrt(p * (1 - p) / n) # === 본 코드 === p = 0.88 # 두 가지 표본 크기 비교 for n in [1000, 50]: se = se_proportion(p, n) print(f"n = {n:>5}: SE = {se:.4f}") print() print("→ 더 큰 표본 크기 = 더 작은 표준오차") print(" n이 4배가 되면 SE는 절반으로 줄어든다 (∝ 1/√n).")
해석 보기

$n = 50$일 때 $SE \approx 0.046$이고, $n = 1000$일 때 $SE \approx 0.010$이다. 약 4.47배 차이가 난다. 이는 표준오차가 $1/\sqrt{n}$에 비례한다는 사실에서 비롯된다 ($\sqrt{1000/50} = \sqrt{20} \approx 4.47$).

결론: 더 큰 표본은 더 작은 표본보다 더 정확한 점추정값을 제공하는 경향이 있다.

5.1.3 중심극한정리

중심극한정리와 성공-실패 조건

관측값들이 독립이고 표본 크기가 충분히 크면, 표본비율 $\hat{p}$은 다음의 평균과 표준오차를 가진 정규분포를 따르는 경향이 있다.

$$\mu_{\hat{p}} = p, \qquad SE_{\hat{p}} = \sqrt{\frac{p(1-p)}{n}}$$

성공-실패 조건(success-failure condition): $np \geq 10$이고 $n(1-p) \geq 10$일 때 표본 크기가 충분하다고 본다.

5.1.4 플러그인 원리

실제 연구에서는 모집단비율 $p$를 알지 못한다. 따라서 성공-실패 조건을 확인하거나 표준오차를 계산할 때, $p$ 대신 $\hat{p}$를 대체하여 사용한다. 이를 플러그인 원리(plug-in principle)라 한다.

$$SE_{\hat{p}} = \sqrt{\frac{p(1-p)}{n}} \approx \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$$
◈ 새로운 시각
플러그인 원리의 실용성

실제 연구에서는 거의 항상 $p$를 모르므로 $\hat{p}$를 대신 사용하는 플러그인 원리가 매우 중요하다.

  1. 신뢰구간 계산: $SE = \sqrt{\hat{p}(1-\hat{p})/n}$ 사용
  2. 조건 확인: $n\hat{p} \geq 10$, $n(1-\hat{p}) \geq 10$ 확인

이 방법이 작동하는 이유는 표본 크기가 충분히 크면 $\hat{p}$이 $p$에 가까워지기 때문이다.

5.2 비율에 대한 신뢰구간

5.2.1 모집단 모수 포착하기

점추정값만 사용하는 것은 흐린 호수에서 작살로 물고기를 잡으려는 것과 같다. 반면 그물을 던지면 물고기를 잡을 좋은 기회를 얻는다. 신뢰구간(confidence interval)은 그물로 낚시하는 것에 해당하며, 모집단 모수가 있을 가능성이 큰 값들의 범위를 나타낸다.

5.2.2 95% 신뢰구간 구성

점추정값 분포가 정규분포에 가까울 때, 95% 신뢰구간은 다음과 같이 구성한다.

$$\text{점추정값} \pm 1.96 \times SE$$

일반적인 신뢰수준에 대한 신뢰구간은 다음 형태이다.

$$\text{점추정값} \pm z^* \times SE$$
신뢰수준$z^*$각 꼬리 면적
90%1.6455%
95%1.9602.5%
99%2.5760.5%
Example 5.8
태양 에너지 지지율 — 95% 신뢰구간
[문제] 1000명의 미국 성인 무작위 표본 중 88.7%가 태양열 발전 확대를 지지한다. 95% 신뢰구간을 구하고 해석하라.
# === 도우미 함수 === import math from scipy import stats def check_success_failure(p, n, t=10): s, f = n*p, n*(1-p); return s>=t and f>=t, s, f def confidence_interval_p(p_hat, n, conf=0.95): z_star = stats.norm.ppf((1+conf)/2); se = math.sqrt(p_hat*(1-p_hat)/n) return (p_hat-z_star*se, p_hat+z_star*se), z_star, se # === 본 코드 === p_hat = 0.887 n = 1000 # 조건 확인 → SE 계산 → 신뢰구간 ok, s, f = check_success_failure(p_hat, n) ci, z_star, se = confidence_interval_p(p_hat, n, conf=0.95) print(f"성공-실패 조건: np̂ = {s:.0f}, n(1-p̂) = {f:.0f} → {'✅ 만족' if ok else '❌ 불만족'}") print(f"표준오차: SE = {se:.4f}") print(f"임계값: z* = {z_star:.3f}") print(f"오차한계: margin = {z_star * se:.4f}") print() print(f"95% 신뢰구간: ({ci[0]:.4f}, {ci[1]:.4f})") print(f" = ({ci[0]*100:.1f}%, {ci[1]*100:.1f}%)")
해석 보기

태양열 발전 확대를 지지하는 미국 성인의 실제 비율이 86.7%에서 90.7% 사이에 있다고 95% 확신한다.

주의: "이 구간이 참값을 포함할 확률이 95%"라고 해석하면 안 된다. 정확한 해석은 "이 방법으로 100번 구간을 만들면 약 95번이 참값을 포함한다"이다.

🔧 직접 풀어보기 — 신뢰수준 변경

신뢰수준을 바꾸면 구간 너비가 어떻게 변하는지 관찰해 보자. (앞서 계산한 결과를 함수로 재사용하므로 매번 다시 import하거나 SE를 다시 계산할 필요가 없다.)

# === 도우미 함수 === import math from scipy import stats def confidence_interval_p(p_hat, n, conf=0.95): z_star = stats.norm.ppf((1+conf)/2); se = math.sqrt(p_hat*(1-p_hat)/n) return (p_hat-z_star*se, p_hat+z_star*se), z_star, se # === 본 코드 === # p_hat과 n은 그대로, 신뢰수준만 바꿔서 비교 p_hat = 0.887 n = 1000 print(f"=== p̂ = {p_hat}, n = {n}일 때 신뢰수준별 비교 ===") print() for conf in [0.80, 0.90, 0.95, 0.99]: ci, z_star, se = confidence_interval_p(p_hat, n, conf) width = ci[1] - ci[0] print(f"{int(conf*100):3d}% CI: z*={z_star:.3f} ({ci[0]*100:.2f}%, {ci[1]*100:.2f}%) 너비={width*100:.2f}%") print("\n→ 신뢰수준이 높을수록 구간이 넓어진다 (트레이드오프).")

에볼라 격리 지지율
[문제] 2014년 10월 뉴욕에서 1,042명을 조사한 결과 82%가 에볼라 환자 접촉자에 대한 의무 격리를 지지했다. 95% 신뢰구간을 구하라.

단일 비율에 대한 신뢰구간 구성 단계
  1. 준비(Prepare): $\hat{p}$와 $n$을 식별하고 신뢰수준을 결정한다.
  2. 확인(Check): $\hat{p}$이 거의 정규분포임을 보장하는 조건을 확인한다.
  3. 계산(Calculate): SE를 계산하고 $z^*$를 찾아 구간을 구성한다.
  4. 결론(Conclude): 문제의 맥락에서 신뢰구간을 해석한다.
◈ 새로운 시각
신뢰구간의 참된 의미
  • 신뢰수준(95%)은 방법에 대한 것이지, 특정 구간에 대한 것이 아니다.
  • "이 방법으로 100번 구간을 만들면, 약 95번은 참값을 포함할 것이다"가 올바른 해석이다.
  • 특정 구간에 대해 "참값이 이 구간에 있을 확률이 95%다"라고 말하는 것은 잘못된 해석이다.
  • 모수는 구간 안에 있거나 없다 — 확률의 문제가 아니다!

5.3 비율에 대한 가설검정

본 절에서는 경쟁하는 아이디어와 주장을 엄격하게 평가하는 데 사용되는 프레임워크인 가설검정(hypothesis tests)에 대해 학습한다.

5.3.1 가설검정 프레임워크

귀무가설과 대립가설
  • 귀무가설($H_0$): 회의적인 시각 또는 "아무 일도 일어나지 않았다"는 주장.
  • 대립가설($H_A$): "무언가 새로운 것이 일어나고 있다"는 대안적 주장.

2014년 Pew Research 조사에서 50명의 대학 교육을 받은 미국 성인에게 신생아 백신 접종 일정을 물었다. 응답자의 24%만이 정답("의사 권장대로 빨리 맞아야 한다")을 골랐다. 무작위 추측이라면 1/3 ≈ 33.3%가 정답을 맞혀야 한다. 24%와 33.3%의 차이는 우연인가, 아니면 실제 차이인가?

$H_0: p = 0.333$ (무작위 추측과 같음)
$H_A: p \neq 0.333$ (무작위 추측과 다름)
Example 5.20
신뢰구간을 통한 가설검정
[문제] 50명 중 12명이 정답을 맞혔다($\hat{p} = 0.24$). 95% 신뢰구간을 구성하여 귀무가설 $p_0 = 1/3$을 검정하라.
# === 도우미 함수 === import math from scipy import stats def confidence_interval_p(p_hat, n, conf=0.95): z_star = stats.norm.ppf((1+conf)/2); se = math.sqrt(p_hat*(1-p_hat)/n) return (p_hat-z_star*se, p_hat+z_star*se), z_star, se # === 본 코드 === p_hat = 12 / 50 # 0.24 n = 50 p0 = 1/3 # 5.2절에서 정의한 confidence_interval_p 함수를 그대로 재사용 ci, z_star, se = confidence_interval_p(p_hat, n, conf=0.95) print(f"표본비율: p̂ = {p_hat}") print(f"표준오차: SE = {se:.4f}") print(f"95% CI: ({ci[0]:.3f}, {ci[1]:.3f})") print() print(f"귀무값 p₀ = {p0:.3f}") print(f"귀무값이 95% CI 내에 있는가? {'✅ 예' if ci[0] <= p0 <= ci[1] else '❌ 아니오'}") print() if ci[0] <= p0 <= ci[1]: print("→ 결론: H₀를 기각하지 않는다. 차이를 우연으로 설명할 수 있다.") else: print("→ 결론: H₀를 기각한다.")

5.3.3 의사결정 오류

$H_0$가 참$H_A$가 참
$H_0$ 기각하지 않음올바른 결정제2종 오류
$H_0$ 기각제1종 오류올바른 결정

제1종 오류(Type I Error): $H_0$가 실제로 참일 때 귀무가설을 기각.
제2종 오류(Type II Error): $H_A$가 실제로 참일 때 귀무가설을 기각하지 못함.

유의수준(significance level) $\alpha$는 귀무가설이 참일 때 데이터가 $H_0$를 잘못 기각하도록 이끄는 빈도이다. 일반적인 값은 $\alpha = 0.05$이다.

5.3.4 p-값을 사용한 공식적인 검정

p-값 정의
p-값은 귀무가설이 참이라면, 현재 데이터 세트만큼 대립가설에 유리하거나 더 유리한 데이터를 관찰할 확률이다.
Example 5.28
석탄 에너지 지지율 — Z-검정
[문제] 1000명 중 37%만이 석탄 에너지 확대를 지지했다. 미국 성인의 과반수가 석탄 에너지 확대에 찬성하지 않는다는 강력한 증거가 있는가?
# === 도우미 함수 === import math from scipy import stats def z_test_proportion(p_hat, p0, n): se = math.sqrt(p0*(1-p0)/n); z = (p_hat-p0)/se return z, 2*(1 - stats.norm.cdf(abs(z))), se # === 본 코드 === p_hat = 0.37 p0 = 0.5 n = 1000 alpha = 0.05 # z_test_proportion 함수로 검정 수행 z, p_value, se = z_test_proportion(p_hat, p0, n) print(f"H₀: p = {p0}") print(f"Hₐ: p ≠ {p0}") print(f"유의수준 α = {alpha}") print() print(f"표본비율: p̂ = {p_hat}") print(f"표준오차 (귀무값으로 계산): SE = {se:.4f}") print(f"검정통계량: Z = ({p_hat} - {p0})/{se:.4f} = {z:.2f}") print(f"양측 p-값: = {p_value:.2e}") print() if p_value < alpha: print(f"→ p-값 < α 이므로 H₀를 기각한다.") print(f" 결론: 미국 성인의 과반수가 석탄 에너지 확대를 지지하지 않는다는 강력한 증거.") else: print(f"→ p-값 ≥ α 이므로 H₀를 기각하지 않는다.")
풀이 단계 보기
  1. 가설: $H_0: p = 0.5$, $H_A: p \neq 0.5$
  2. 조건 확인: $np_0 = 500 \ge 10$, $n(1-p_0) = 500 \ge 10$ ✓
  3. 표준오차(귀무값 사용): $SE = \sqrt{0.5 \cdot 0.5 / 1000} \approx 0.0158$
  4. Z-점수: $Z = (0.37 - 0.5)/0.0158 \approx -8.23$
  5. p-값 $\approx 0$, 따라서 $H_0$를 기각.

결론: 미국 성인의 과반수가 석탄 에너지 확대를 지지하지 않는다는 매우 강력한 증거가 있다.

🔧 직접 풀어보기 — 같은 함수로 다양한 검정 즉시 수행

$\hat{p}$, $p_0$, $n$ 값만 바꾸면 같은 z_test_proportion 함수로 다양한 검정을 즉시 수행할 수 있다. 매번 SE와 Z를 다시 import하거나 새로 정의할 필요가 없다.

# === 도우미 함수 === import math from scipy import stats def z_test_proportion(p_hat, p0, n): se = math.sqrt(p0*(1-p0)/n); z = (p_hat-p0)/se return z, 2*(1 - stats.norm.cdf(abs(z))), se # === 본 코드 === # 시도해 볼 시나리오들 (값을 바꿔보자) 시나리오 = [ ("핵무기 감축 지지율 (예제 5.33)", 0.56, 0.50, 1028), ("최저임금 지지율 (연습 5.21)", 0.42, 0.50, 1000), ("근시 비율 (연습 5.32)", 21/194, 0.08, 194), ] print(f"{'사례':<35} {'p̂':>7} {'p₀':>6} {'n':>5} {'Z':>7} {'p-값':>10} {'결론':<10}") print("-" * 90) for name, p_hat, p0, n in 시나리오: z, p_value, se = z_test_proportion(p_hat, p0, n) decision = "H₀ 기각" if p_value < 0.05 else "H₀ 유지" print(f"{name:<35} {p_hat:>7.3f} {p0:>6.2f} {n:>5} {z:>+7.2f} {p_value:>10.4f} {decision:<10}")
◈ 새로운 시각
빅 데이터 시대의 통계적 vs 실질적 유의성

표본 크기가 매우 크면 실질적 가치가 없는 작은 차이도 통계적으로 유의하게 감지될 수 있다. 데이터 과학에서 빅 데이터가 보편화됨에 따라 이 구분은 매우 중요해졌다.

  • 수백만 명의 데이터가 있으면 거의 모든 작은 차이도 통계적으로 유의해질 수 있다.
  • "통계적으로 유의미하다"와 "실제로 중요하다"는 매우 다른 질문이다.
  • 항상 효과 크기(effect size)를 검토하고 실제 응용에서 의미가 있는지 질문해야 한다.
  • p-값만 보고하지 말고 신뢰구간이나 효과 크기도 함께 보고하는 것이 좋은 관행이다.
Exercise 5.35 시연
표본 크기에 따른 검정 결과 변화
[문제] 효과 크기 1%(0.51 vs 0.50)의 같은 차이라도 표본 크기에 따라 검정 결과가 달라진다. 직접 확인해 보자.
# === 도우미 함수 === import math from scipy import stats def z_test_proportion(p_hat, p0, n): se = math.sqrt(p0*(1-p0)/n); z = (p_hat-p0)/se return z, 2*(1 - stats.norm.cdf(abs(z))), se # === 본 코드 === # 효과 크기는 고정 (1%), 표본 크기만 변화 p_hat = 0.51 p0 = 0.50 print(f"고정된 효과 크기: {(p_hat - p0)*100:.1f}% (실질적으로 매우 작음)") print() print(f"{'n':>8} {'SE':>8} {'Z':>7} {'p-값':>10} {'유의?':>10}") print("-" * 50) for n in [100, 1000, 10000, 100000]: z, p_value, se = z_test_proportion(p_hat, p0, n) sig = "유의" if p_value < 0.05 else "유의 안 함" print(f"{n:>8} {se:>8.4f} {z:>+7.2f} {p_value:>10.4f} {sig:>10}") print("\n→ 같은 1% 차이라도 n이 클수록 통계적으로 유의해진다.") print(" 하지만 1% 차이가 실제 의사결정에서 중요한가? 별개의 질문이다.")

Exercise 5.32
근시 비율 검정
[문제] 근시는 모든 어린이의 약 8%에게 영향을 미친다고 알려져 있다. 194명의 표본에서 21명이 근시였다. 8%가 정확하지 않다는 증거가 있는가?
# === 도우미 함수 === import math from scipy import stats def z_test_proportion(p_hat, p0, n): se = math.sqrt(p0*(1-p0)/n); z = (p_hat-p0)/se return z, 2*(1 - stats.norm.cdf(abs(z))), se # === 본 코드 === # 같은 z_test_proportion 함수를 그대로 재사용 p_hat = 21 / 194 p0 = 0.08 n = 194 alpha = 0.05 z, p_value, se = z_test_proportion(p_hat, p0, n) print(f"H₀: p = {p0}") print(f"Hₐ: p ≠ {p0}") print() print(f"표본비율: p̂ = {p_hat:.4f}") print(f"SE = {se:.4f}") print(f"Z = {z:.2f}") print(f"p-값 = {p_value:.3f}") print() print(f"결론: {'H₀ 기각' if p_value < alpha else 'H₀ 기각 실패 — 8%가 부정확하다는 충분한 증거 없음'}")
해석 보기

$\hat{p} = 21/194 \approx 0.108$, $SE \approx 0.0195$, $Z \approx 1.44$, p-값 $\approx 0.150$이다.

p-값 (0.150) > $\alpha$ (0.05)이므로 $H_0$를 기각하지 않는다. 즉 8%가 정확하지 않다는 충분한 증거가 없다.

◈ 새로운 시각
가설검정의 한계와 대안

가설검정은 강력한 도구이지만 한계가 있다.

  1. 이분법적 결론: "기각" 또는 "기각하지 않음"만 있다.
  2. p-값 오용: p-값 = 0.049와 p-값 = 0.051이 질적으로 다른가?
  3. 효과 크기 무시: 통계적으로 유의해도 실질적으로 의미 없을 수 있다.

대안과 보완책: 신뢰구간을 함께 보고하고, 효과 크기(Cohen's d 등)를 계산하며, 베이지안 접근법을 고려하고, 재현성 연구를 수행하는 것이 좋다. 좋은 연구는 p-값뿐 아니라 효과의 크기와 실질적 의미를 함께 고려한다.
