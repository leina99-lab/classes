SECTION 6.1

단일 비율에 대한 추론

제5장에서 점추정, 신뢰구간, 가설검정을 탐구하면서 단일 비율에 대한 추론 방법을 접하였다. 이 절에서는 이러한 주제를 복습하고, 단일 비율 상황에서 자료를 수집할 때 적절한 표본크기를 선택하는 방법도 함께 다룬다.

6.1.1 표본비율이 근사적으로 정규분포를 따르는 조건

표본 관측값이 독립이고 표본크기가 충분히 클 때, 표본비율 $\hat{p}$은 정규분포를 사용하여 모형화할 수 있다.

$\hat{p}$의 표집분포 참 비율이 $p$인 모집단에서 크기 $n$인 표본에 기초한 $\hat{p}$의 표집분포는 다음 두 조건이 충족될 때 근사적으로 정규분포를 따른다.
  1. 표본의 관측값이 독립이다(예: 단순무작위표본).
  2. 표본에서 최소 10개의 성공과 10개의 실패가 예상된다. 즉 $np \geq 10$이고 $n(1-p) \geq 10$이다. 이를 성공-실패 조건(success-failure condition)이라 한다.
조건이 충족되면 $\hat{p}$의 표집분포는 평균 $p$, 표준오차 $SE = \sqrt{p(1-p)/n}$인 근사 정규분포를 따른다.

일반적으로 참 비율 $p$는 알려져 있지 않으므로, 조건을 확인하고 표준오차를 추정할 때 어떤 값을 대입한다. 신뢰구간의 경우 표본비율 $\hat{p}$을 사용하고, 가설검정의 경우 일반적으로 귀무값 $p_0$을 사용한다.

새로운 시각: 성공-실패 조건의 직관적 이해

성공-실패 조건 $np \geq 10$, $n(1-p) \geq 10$은 왜 필요한가? 이는 이항분포의 정규근사가 충분히 정확해지는 시점을 보장하는 경험 법칙이다.

핵심 통찰: 이항분포는 본질적으로 이산분포이므로 성공 횟수는 $0, 1, 2, \ldots, n$의 정수값만 가질 수 있다. 반면 정규분포는 연속분포이다. 성공-실패 조건은 이산적인 막대그래프가 연속적인 종 모양 곡선과 충분히 비슷해지는 시점을 보장한다.

기하학적 해석: $n$이 작거나 $p$가 0 또는 1에 가까우면 이항분포가 심하게 치우친다. 예를 들어 $n=20$, $p=0.05$이면 $np=1$로 조건이 충족되지 않으며 분포가 오른쪽으로 심하게 치우치므로 정규근사가 실패한다.

역사적 배경: 드 무아브르(de Moivre)가 1733년에 이항분포의 정규근사를 처음 발견하였다. 그러나 실용적인 "10의 규칙"은 20세기 통계 실무에서 경험적으로 확립된 것이다.

아래 셀로 직접 확인해 보십시오. $p$와 $n$ 값을 바꾸어 가며 이항분포가 정규분포에 얼마나 가까워지는지 시각적으로 비교할 수 있다.

아래 코드의 p와 n 값을 바꾸어 분포 모양의 변화를 관찰해 보십시오.
import matplotlib.pyplot as plt import numpy as np from scipy import stats # === 학생이 바꾸어 볼 변수 === p = 0.3 # 성공 확률 (0 ~ 1) n = 50 # 시행 횟수 # =========================== x = np.arange(0, n+1) binom_pmf = stats.binom.pmf(x, n, p) mu, sigma = n*p, np.sqrt(n*p*(1-p)) xs = np.linspace(max(0, mu-4*sigma), min(n, mu+4*sigma), 200) norm_pdf = stats.norm.pdf(xs, mu, sigma) fig, ax = plt.subplots(figsize=(8, 4)) ax.bar(x, binom_pmf, alpha=0.5, label=f'Binomial(n={n}, p={p})') ax.plot(xs, norm_pdf, 'r-', lw=2, label=f'Normal(mu={mu:.1f}, sd={sigma:.2f})') ax.set_xlabel('Number of successes'); ax.set_ylabel('Probability') ax.legend(); ax.set_title(f'np = {n*p:.1f}, n(1-p) = {n*(1-p):.1f}') plt.show() print(f"성공-실패 조건: np = {n*p:.1f}, n(1-p) = {n*(1-p):.1f}") print(f"두 값이 모두 10 이상인가? {n*p >= 10 and n*(1-p) >= 10}")

6.1.2 비율에 대한 신뢰구간

신뢰구간은 모수 $p$에 대한 그럴듯한 값의 범위를 제공한다. $\hat{p}$이 정규분포로 모형화될 수 있을 때, $p$에 대한 신뢰구간은 다음 형태를 갖는다.

$$\hat{p} \pm z^{\ast} \times SE$$
예제 6.1
조건 확인 — 페이데이 대출 차입자 조사
[문제] 826명의 급여담보대출(payday loan) 차입자를 대상으로 한 단순무작위표본 조사에서 응답자의 70%가 급여담보대출 업체에 대한 새로운 규제를 지지하였다. $\hat{p}=0.70$을 정규분포로 모형화하는 것이 타당한가?
풀이 보기

자료가 무작위표본이므로 관측값은 독립이고 관심 모집단을 대표한다. 신뢰구간 맥락이므로 $p$ 대신 $\hat{p}$을 사용하여 성공-실패 조건을 확인한다.

$$n\hat{p} = 826 \times 0.70 = 578, \qquad n(1-\hat{p}) = 826 \times 0.30 = 248$$

두 값 모두 10 이상이므로 $\hat{p}$을 정규분포로 모형화할 수 있다.

n = 826 p_hat = 0.70 successes = n * p_hat failures = n * (1 - p_hat) print(f"성공 횟수 (n*p_hat): {successes:.0f}") print(f"실패 횟수 n(1-p_hat): {failures:.0f}") print(f"성공-실패 조건 충족 여부: {successes >= 10 and failures >= 10}")
예제 6.3
95% 신뢰구간의 구성
[문제] 위 조사에서 규제를 지지하는 차입자 비율 $p$에 대한 95% 신뢰구간을 구성하라.
풀이 보기

점추정 $\hat{p}=0.70$, $z^{\ast}=1.96$, 표준오차 $SE = \sqrt{0.70 \times 0.30 / 826} \approx 0.016$이다.

$$0.70 \pm 1.96 \times 0.016 \;\rightarrow\; (0.669, \, 0.731)$$

여론조사 시점에 규제를 지지하는 참 비율이 $0.669$에서 $0.731$ 사이에 있다고 95% 신뢰한다.

import numpy as np from scipy import stats # === 변수 === n = 826 p_hat = 0.70 confidence_level = 0.95 # =========== se = np.sqrt(p_hat * (1 - p_hat) / n) z_star = stats.norm.ppf((1 + confidence_level) / 2) me = z_star * se print(f"표준오차 SE = {se:.4f}") print(f"임계값 z* = {z_star:.4f}") print(f"오차한계 ME = {me:.4f}") print(f"{int(confidence_level*100)}% 신뢰구간: ({p_hat-me:.3f}, {p_hat+me:.3f})")
신뢰수준을 90%, 99% 등으로 바꾸어 신뢰구간의 폭이 어떻게 변화하는지 직접 확인해 보십시오.
import numpy as np from scipy import stats # === 학생이 바꾸어 볼 변수 === n = 826 p_hat = 0.70 confidence_level = 0.95 # 0.90, 0.95, 0.99 등으로 변경 # =========================== se = np.sqrt(p_hat * (1 - p_hat) / n) z_star = stats.norm.ppf((1 + confidence_level) / 2) me = z_star * se print(f"신뢰수준: {confidence_level*100:.0f}%") print(f"임계값 z* = {z_star:.4f}") print(f"오차한계 = {me:.4f}") print(f"신뢰구간: ({p_hat-me:.4f}, {p_hat+me:.4f})") print(f"구간의 폭: {2*me:.4f}")

6.1.3 비율에 대한 가설검정

가설검정의 절차는 다음과 같다. 우선 가설을 설정하고, 정규근사 조건을 확인한 뒤(이때는 귀무값 $p_0$를 사용한다), 검정통계량과 $p$-값을 계산하여 결론을 내린다.

예제 6.6
단일 비율 양측 검정 — 신용조회 규제 지지율
[문제] 826명 차입자 무작위표본에서 51%가 새로운 신용조회 규제를 지지한다고 응답하였다. 차입자의 다수가 이 규제를 지지(또는 반대)한다는 설득력 있는 증거가 있는가? 유의수준 $\alpha = 0.05$로 검정하라.
풀이 보기

가설: $H_0: p = 0.50$, $H_A: p \neq 0.50$

조건 확인(귀무값 사용): $np_0 = n(1-p_0) = 413 \geq 10$이므로 정규근사가 가능하다.

표준오차: $SE = \sqrt{0.5 \times 0.5 / 826} \approx 0.017$

검정통계량: $Z = (0.51 - 0.50)/0.017 = 0.59$

$p$-값(양측): $2 \times P(Z > 0.59) \approx 0.555$

결론: $p$-값이 $\alpha=0.05$보다 크므로 $H_0$을 기각하지 못한다. 차입자의 다수가 이 규제에 대해 일관된 입장을 가진다는 설득력 있는 증거는 없다.

import numpy as np from scipy import stats # === 변수 === n = 826 p_hat = 0.51 p_0 = 0.50 alpha = 0.05 # =========== se = np.sqrt(p_0 * (1 - p_0) / n) # 가설검정에서는 귀무값 사용 z = (p_hat - p_0) / se p_value = 2 * (1 - stats.norm.cdf(abs(z))) print(f"표준오차 SE (귀무값 사용) = {se:.4f}") print(f"검정통계량 Z = {z:.3f}") print(f"p-값 = {p_value:.4f}") print(f"결론: H0를 {'기각한다' if p_value < alpha else '기각하지 못한다'}")
새로운 시각: 신뢰구간과 가설검정에서 표준오차의 차이

학생들이 자주 혼란스러워하는 부분이 있다. 왜 신뢰구간에서는 $\hat{p}$을 사용하고, 가설검정에서는 $p_0$을 사용하는가?

맥락사용하는 비율이유
신뢰구간 $\hat{p}$ (표본비율) 모수 $p$의 범위를 추정하는 것이 목적이다. $p$를 모르므로 최선의 추정값인 $\hat{p}$을 사용한다.
가설검정 $p_0$ (귀무값) "귀무가설이 참이라면"이라는 조건부 세계에서 분석한다. 따라서 $p = p_0$을 가정한다.

직관적 이해: 가설검정은 검찰의 역할과 비슷하다. 피고인(귀무가설)이 무죄(참)라고 가정하고 시작하여, 그 가정 하에서 관측된 증거가 얼마나 이상한지를 평가한다. 따라서 모든 계산을 $p_0$ 가정 위에서 수행해야 한다.

6.1.5 비율 추정을 위한 표본크기 결정

자료를 수집할 때 적절한 표본크기를 선택해야 한다. 일반적으로 오차한계 $ME$가 충분히 작도록 다음을 만족하는 가장 작은 $n$을 찾는다.

$$z^{\ast}\sqrt{\frac{p(1-p)}{n}} \leq ME \;\;\Longleftrightarrow\;\; n \geq \frac{p(1-p)\,(z^{\ast})^{2}}{ME^{2}}$$
예제 6.7
표본크기 계산 — 등록금 인상 설문
[문제] 95% 신뢰수준에서 오차한계가 0.04보다 작도록 하려면 몇 명을 표본에 포함해야 하는가? $p$에 대한 사전 정보가 없는 경우와, $p \approx 0.35$의 사전 정보가 있는 경우를 비교하라.
풀이 보기

$p$를 모를 때는 $p(1-p)$를 최대화하는 $p=0.5$를 보수적으로 사용한다.

$$n \geq \frac{0.25 \times 1.96^{2}}{0.04^{2}} = 600.25 \;\Rightarrow\; n = 601$$

$p \approx 0.35$인 경우 $p(1-p) = 0.2275$이므로

$$n \geq \frac{0.2275 \times 1.96^{2}}{0.04^{2}} = 546.2 \;\Rightarrow\; n = 547$$

사전 정보가 있을 때 더 작은 표본으로도 동일한 정밀도를 달성할 수 있다.

import numpy as np from scipy import stats ME = 0.04 conf = 0.95 z_star = stats.norm.ppf((1 + conf) / 2) # 사전 정보 없음 (p = 0.5 보수적) p1 = 0.5 n1 = p1 * (1 - p1) * (z_star / ME)**2 # 사전 정보 있음 (p = 0.35) p2 = 0.35 n2 = p2 * (1 - p2) * (z_star / ME)**2 print(f"사전 정보 없음 (p=0.5): n >= {np.ceil(n1):.0f}") print(f"사전 정보 있음 (p=0.35): n >= {np.ceil(n2):.0f}") print(f"절약된 표본 수: {np.ceil(n1) - np.ceil(n2):.0f} 명")
새로운 시각: $p(1-p)$ 함수와 표본크기 계산

표본크기 공식의 핵심에 있는 함수 $f(p) = p(1-p) = p - p^{2}$는 위로 볼록한 이차함수이다. $f'(p) = 1 - 2p = 0$을 풀면 $p = 0.5$에서 최댓값 $0.25$를 가진다.

직관적 의미: $p = 0.5$일 때 불확실성이 최대이다. 성공과 실패가 반반일 때 가장 예측하기 어렵다. 반면 $p$가 0이나 1에 가까우면 거의 모든 결과가 한쪽으로 쏠리므로 예측이 쉬워진다.

실용적 함의: 사전 정보가 없을 때 $p = 0.5$를 사용하면 "최악의 시나리오"에 대비한 보수적 표본크기를 얻는다. 사전 정보가 있다면 더 작은 표본으로 동일한 정밀도를 달성할 수 있다.

아래 코드는 $p(1-p)$ 함수를 시각화한다. 곡선이 $p=0.5$에서 최대가 되는 것을 확인하라.
import numpy as np import matplotlib.pyplot as plt p = np.linspace(0, 1, 200) f = p * (1 - p) fig, ax = plt.subplots(figsize=(7, 4)) ax.plot(p, f, 'b-', lw=2) ax.axvline(0.5, color='red', linestyle='--', alpha=0.5) ax.axhline(0.25, color='red', linestyle='--', alpha=0.5) ax.scatter([0.5], [0.25], color='red', s=80, zorder=5) ax.annotate('Maximum at p=0.5\n f(0.5) = 0.25', xy=(0.5, 0.25), xytext=(0.65, 0.20), fontsize=11, color='red') ax.set_xlabel('p'); ax.set_ylabel('p(1-p)') ax.set_title('Variance function p(1-p)') ax.grid(True, alpha=0.3) plt.show()
연습문제 6.1
대학 흡연자 비율 추정

한 대학에서 학생 200명을 무작위로 추출하여 조사한 결과 40명이 흡연자였다.

  1. 흡연자 비율에 대한 90% 신뢰구간을 구성하라.
  2. 오차한계를 절반으로 줄이려면 표본을 몇 명으로 해야 하는가?
  3. 흡연율이 25%라는 주장에 대해 양측 검정을 수행하라($\alpha = 0.05$).
힌트: 신뢰구간에서는 $\hat{p}$, 가설검정에서는 $p_0 = 0.25$를 표준오차에 사용한다. 표본크기 4배가 오차한계 절반에 해당함을 기억하라.

import numpy as np from scipy import stats # === 주어진 자료 === n = 200 smokers = 40 p_hat = smokers / n # ================== # (1) 90% 신뢰구간 — 코드를 완성하시오 conf = 0.90 se_ci = np.sqrt(p_hat * (1 - p_hat) / n) z_star = stats.norm.ppf((1 + conf) / 2) print(f"점추정: {p_hat:.3f}") print(f"표준오차(신뢰구간용): {se_ci:.4f}") # ME = ? # 신뢰구간 = ? # (2) 오차한계 절반에 필요한 표본크기 — 코드를 완성하시오 # 힌트: 새 ME = 기존 ME / 2 → n은 4배 필요 # (3) p_0 = 0.25 양측 검정 — 코드를 완성하시오 p_0 = 0.25 # se_test = ? # z = ? # p_value = ?
정답 및 풀이 보기

(1) $SE_{\text{CI}} = \sqrt{0.20 \times 0.80 / 200} \approx 0.0283$, $z^{\ast}=1.645$이므로 $0.20 \pm 1.645 \times 0.0283 \to (0.153, 0.247)$.

(2) $ME$를 절반으로 만들려면 $n$이 4배가 되어야 한다. 따라서 $n=800$.

(3) $SE_{\text{test}} = \sqrt{0.25 \times 0.75 / 200} \approx 0.0306$, $Z = (0.20-0.25)/0.0306 \approx -1.63$, 양측 $p$-값 $\approx 0.103$. $\alpha=0.05$에서 $H_0$을 기각하지 못한다.

import numpy as np from scipy import stats n = 200 smokers = 40 p_hat = smokers / n # (1) 90% 신뢰구간 conf = 0.90 se_ci = np.sqrt(p_hat * (1 - p_hat) / n) z_star = stats.norm.ppf((1 + conf) / 2) me = z_star * se_ci print("(1) 90% 신뢰구간") print(f" SE = {se_ci:.4f}, ME = {me:.4f}") print(f" 구간: ({p_hat - me:.3f}, {p_hat + me:.3f})") # (2) ME 절반 → n 4배 print(f"\n(2) ME 절반에 필요한 표본크기: n = {4*n}") # (3) p_0 = 0.25 양측 검정 p_0 = 0.25 se_test = np.sqrt(p_0 * (1 - p_0) / n) z = (p_hat - p_0) / se_test p_value = 2 * (1 - stats.norm.cdf(abs(z))) print(f"\n(3) 가설검정 (p_0 = 0.25)") print(f" SE = {se_test:.4f}, Z = {z:.3f}") print(f" 양측 p-값 = {p_value:.4f}") print(f" 결론: H0를 {'기각' if p_value < 0.05 else '기각하지 못한다'}")
SECTION 6.2

두 비율의 차이

이 절에서는 두 그룹의 성공 비율을 비교하는 상황을 다룬다. 점추정은 $\hat{p}_{1} - \hat{p}_{2}$이며, 단일 비율 상황과 동일한 절차(조건 확인 → 표준오차 계산 → 추론)를 따른다.

6.2.1 $\hat{p}_{1} - \hat{p}_{2}$의 표집분포

정규근사 조건 $\hat{p}_{1} - \hat{p}_{2}$은 다음 조건이 충족될 때 정규분포로 모형화할 수 있다.
  • 독립성(확장): 자료가 두 그룹 내에서 그리고 두 그룹 사이에서 독립이다.
  • 성공-실패 조건: 두 그룹 모두에서 각각 성공과 실패의 기대 횟수가 10 이상이다.
조건이 충족되면 표준오차는 다음과 같다. $$SE = \sqrt{\frac{p_{1}(1-p_{1})}{n_{1}} + \frac{p_{2}(1-p_{2})}{n_{2}}}$$
새로운 시각: 두 비율 차이의 분산 공식

두 독립 확률변수 $X, Y$의 차에 대해 다음이 성립한다.

$$\mathrm{Var}(X - Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$$

차이를 구하더라도 분산은 더해진다. 직관에 반하는 듯 보이지만, 두 불확실한 양을 비교할 때 첫 번째가 실제보다 높게 추정되고 두 번째가 실제보다 낮게 추정되는 경우 두 오차가 결합되어 차이의 불확실성이 오히려 커지기 때문이다.

따라서 $\mathrm{Var}(\hat{p}_{1} - \hat{p}_{2}) = \mathrm{Var}(\hat{p}_{1}) + \mathrm{Var}(\hat{p}_{2})$이며, 표준오차는 그 제곱근이다.

6.2.2 $p_{1} - p_{2}$에 대한 신뢰구간

$$\hat{p}_{1} - \hat{p}_{2} \pm z^{\ast} \sqrt{\frac{\hat{p}_{1}(1-\hat{p}_{1})}{n_{1}} + \frac{\hat{p}_{2}(1-\hat{p}_{2})}{n_{2}}}$$
예제 6.12
CPR 연구 — 90% 신뢰구간
[문제] 심정지 환자에 대해 혈전용해제 처치군과 대조군의 24시간 생존율을 비교하였다.
생존사망합계
대조군113950
처치군142640
처치군과 대조군의 생존율 차이에 대한 90% 신뢰구간을 구성하라.
풀이 보기

조건 확인: 두 그룹 모두 성공/실패가 10 이상(11, 39, 14, 26).

점추정: $\hat{p}_{T} - \hat{p}_{C} = 14/40 - 11/50 = 0.35 - 0.22 = 0.13$

표준오차(신뢰구간용 — 각 표본비율 사용):

$$SE = \sqrt{\frac{0.35 \times 0.65}{40} + \frac{0.22 \times 0.78}{50}} \approx 0.095$$

90% 신뢰구간: $0.13 \pm 1.645 \times 0.095 \to (-0.026, 0.286)$

해석: 신뢰구간이 0을 포함하므로 혈전용해제가 생존율에 영향을 미치지 않을 가능성도 배제할 수 없다.

import numpy as np from scipy import stats # 처치군 n_T = 40; survived_T = 14 # 대조군 n_C = 50; survived_C = 11 p_T = survived_T / n_T p_C = survived_C / n_C diff = p_T - p_C se = np.sqrt(p_T*(1-p_T)/n_T + p_C*(1-p_C)/n_C) conf = 0.90 z_star = stats.norm.ppf((1 + conf) / 2) me = z_star * se print(f"처치군 생존율: {p_T:.3f}") print(f"대조군 생존율: {p_C:.3f}") print(f"점추정 (p_T - p_C): {diff:.3f}") print(f"표준오차: {se:.4f}") print(f"90% 신뢰구간: ({diff-me:.3f}, {diff+me:.3f})") print(f"0을 포함하는가? {'예' if diff-me <= 0 <= diff+me else '아니오'}")

6.2.3 두 비율의 차이에 대한 가설검정

$H_{0}: p_{1} = p_{2}$를 검정할 때, 귀무가설 하에서 두 비율이 같으므로 두 표본을 합쳐 합동 비율(pooled proportion)을 사용한다.

합동 비율과 표준오차 $$\hat{p}_{\text{pool}} = \frac{x_{1}+x_{2}}{n_{1}+n_{2}}, \qquad SE_{\text{test}} = \sqrt{\hat{p}_{\text{pool}}(1-\hat{p}_{\text{pool}})\!\left(\frac{1}{n_{1}} + \frac{1}{n_{2}}\right)}$$
예제 6.14
합동 비율을 사용한 가설검정 — 승진율 비교
[문제] 남성 21명 중 14명 승진, 여성 24명 중 12명 승진. 남녀 승진율이 다른지 $\alpha=0.05$로 검정하라.
풀이 보기

가설: $H_{0}: p_{m} = p_{f}$, $H_{A}: p_{m} \neq p_{f}$

합동 비율: $(14+12)/(21+24) = 26/45 \approx 0.578$

표준오차: $\sqrt{0.578 \times 0.422 \times (1/21 + 1/24)} \approx 0.148$

$Z$: $(0.667-0.500)/0.148 \approx 1.13$, $p$-값 $\approx 0.258$

결론: $p$-값이 $\alpha$보다 크므로 $H_0$을 기각하지 못한다. 남녀 승진율이 다르다는 충분한 증거가 없다.

import numpy as np from scipy import stats # === 자료 === n_m, x_m = 21, 14 n_f, x_f = 24, 12 alpha = 0.05 # ============ p_m = x_m / n_m p_f = x_f / n_f diff = p_m - p_f # 합동 비율 p_pool = (x_m + x_f) / (n_m + n_f) se = np.sqrt(p_pool * (1 - p_pool) * (1/n_m + 1/n_f)) z = diff / se p_value = 2 * (1 - stats.norm.cdf(abs(z))) print(f"남성 승진율: {p_m:.3f}") print(f"여성 승진율: {p_f:.3f}") print(f"합동 비율: {p_pool:.3f}") print(f"표준오차(합동): {se:.4f}") print(f"검정통계량 Z: {z:.3f}") print(f"양측 p-값: {p_value:.4f}") print(f"결론: H0를 {'기각' if p_value < alpha else '기각하지 못한다'}")
새로운 시각: 신뢰구간 vs 가설검정의 표준오차

두 비율 차이를 분석할 때, 신뢰구간과 가설검정에서 사용하는 표준오차 공식이 다르다.

목적사용하는 비율표준오차 공식
신뢰구간각 그룹의 $\hat{p}_{1}, \hat{p}_{2}$ $\sqrt{\hat{p}_{1}(1-\hat{p}_{1})/n_{1} + \hat{p}_{2}(1-\hat{p}_{2})/n_{2}}$
가설검정합동 비율 $\hat{p}_{\text{pool}}$ $\sqrt{\hat{p}_{\text{pool}}(1-\hat{p}_{\text{pool}})(1/n_{1} + 1/n_{2})}$

이유: 신뢰구간은 두 비율 차이의 불확실성을 추정하므로 각 그룹의 최선 추정치를 사용한다. 가설검정은 $p_{1}=p_{2}$라는 귀무가설 하에서 분석하므로 두 비율이 같다는 가정을 반영한 합동 비율을 사용한다.

아래에서 처치군 $n_T$, 대조군 $n_C$ 등의 값을 바꾸어 검정통계량과 $p$-값이 어떻게 변하는지 관찰해 보십시오.
import numpy as np from scipy import stats # === 두 비율 비교 — 자유롭게 변경 === n_T, x_T = 40, 14 # 처치군 n_C, x_C = 50, 11 # 대조군 # ===================================== p_T, p_C = x_T/n_T, x_C/n_C diff = p_T - p_C # (1) 신뢰구간 SE se_ci = np.sqrt(p_T*(1-p_T)/n_T + p_C*(1-p_C)/n_C) # (2) 가설검정 SE (합동) p_pool = (x_T + x_C) / (n_T + n_C) se_test = np.sqrt(p_pool*(1-p_pool)*(1/n_T + 1/n_C)) z = diff / se_test p_value = 2 * (1 - stats.norm.cdf(abs(z))) print(f"점추정 차이: {diff:.4f}") print(f"신뢰구간용 SE: {se_ci:.4f}") print(f"가설검정용 SE: {se_test:.4f}") print(f"Z = {z:.3f}, 양측 p-값 = {p_value:.4f}")

SECTION 6.3

카이제곱을 이용한 적합도 검정

지금까지 정규분포를 사용한 단일 비율 및 두 비율의 추론을 다루었다. 이 절에서는 관측 도수가 어떤 이론적 분포(예: 균등분포, 기하분포)에 부합하는지를 검정하는 적합도 검정(goodness-of-fit test)을 다룬다. 검정통계량으로는 카이제곱 분포를 따르는 $X^{2}$ 통계량을 사용한다.

카이제곱 검정통계량 $k$개 범주에서 관측 도수 $O_{i}$와 기대 도수 $E_{i}$가 주어졌을 때 $$X^{2} = \sum_{i=1}^{k} \frac{(O_{i} - E_{i})^{2}}{E_{i}} \sim \chi^{2}_{(k-1)}$$
  • 자유도: $df = k - 1$
  • 조건: 모든 기대 도수가 5 이상, 관측은 독립
  • $X^{2}$가 클수록 관측이 기대와 멀어 $H_{0}$을 기각하는 증거가 된다.

6.3.1 카이제곱 분포의 성질

카이제곱 분포는 양의 값만 가지며 오른쪽으로 치우친 분포이다. 자유도가 커질수록 분포의 평균과 분산이 커지고 점차 정규분포에 가까워진다.

자유도 $df$를 바꾸어 카이제곱 분포의 모양 변화를 관찰해 보십시오.
import numpy as np import matplotlib.pyplot as plt from scipy import stats # === 자유도 — 자유롭게 변경 === dfs = [2, 4, 9] # =============================== x = np.linspace(0, 25, 400) fig, ax = plt.subplots(figsize=(8, 4)) for df in dfs: ax.plot(x, stats.chi2.pdf(x, df), lw=2, label=f'df = {df}') ax.set_xlabel('X^2'); ax.set_ylabel('Density') ax.set_title('Chi-square distributions by degrees of freedom') ax.legend(); ax.grid(True, alpha=0.3) plt.show()

6.3.2 적합도 검정 — S&P 500 사례

최근 10년간 S&P 500 일별 자료에서 다음 양일 거래 사이의 양의 수익률 발생 간격(대기 시간)이 거래일 독립을 가정한 기하분포에 부합하는지 검정한다고 하자.

예제 6.36
기하분포 적합도 검정
[문제] 다음과 같이 7개 그룹의 관측 도수 $O_{i}$와 기대 도수 $E_{i}$가 주어졌다. 거래일 독립 가설($H_{0}$)을 $\alpha = 0.05$로 검정하라.
대기 일수1234567+
관측 $O_{i}$71736915569281410
기대 $E_{i}$74333815470321512
풀이 보기

$X^{2} = 0.91 + 2.84 + 0.01 + 0.01 + 0.50 + 0.07 + 0.33 \approx 4.61$, $df = 7-1 = 6$, $p$-값 $\approx 0.595$.

$p$-값이 $\alpha=0.05$보다 매우 크므로 $H_{0}$(거래일이 독립이라는 가정 아래 기하분포에 적합)을 기각하지 못한다. 즉, 자료는 거래일 독립 가설과 일관성을 가진다.

import numpy as np from scipy import stats observed = np.array([717, 369, 155, 69, 28, 14, 10]) expected = np.array([743, 338, 154, 70, 32, 15, 12]) # 각 셀의 카이제곱 기여도 contrib = (observed - expected)**2 / expected print("각 셀의 카이제곱 기여도:") for i, c in enumerate(contrib, 1): print(f" 대기 {i}일: ({observed[i-1]}-{expected[i-1]})^2/{expected[i-1]} = {c:.3f}") X2 = contrib.sum() df = len(observed) - 1 p_value = 1 - stats.chi2.cdf(X2, df) print(f"\n검정통계량 X^2 = {X2:.3f}") print(f"자유도 df = {df}") print(f"p-값 = {p_value:.4f}") print(f"결론: H0를 {'기각' if p_value < 0.05 else '기각하지 못한다'}")
새로운 시각: 적합도 검정의 철학적 의미

S&P 500 사례에서 $p$-값 $\approx 0.595$이므로 기하분포(거래일 독립성)를 기각하지 못하였다. 그러나 이것이 거래일이 확실히 독립임을 증명하는 것은 아니다. 단지 자료가 독립성 가정과 일관성을 가진다는 의미일 뿐이다.

비유: 형사재판에서 무죄 판결을 받았다고 해서 결백이 증명되는 것은 아니다. 단지 유죄를 입증할 증거가 부족했을 뿐이다.

실용적 함의:

  • 주식 시장에서 단순한 패턴(예: 연속 하락 후 상승 확률 증가)을 찾으려는 시도가 자료에서 지지되지 않는다는 것을 보여준다.
  • 이는 "효율적 시장 가설"(EMH)과 일관성을 가지는 결과이다.
  • 그러나 더 정교한 의존 구조까지 부정하는 것은 아니다.
연습문제 6.3
주사위 공정성 검정

한 주사위를 600번 던진 결과 각 면이 나온 횟수가 다음과 같다.

눈123456
관측 도수921101058897108

주사위가 공정하다는 귀무가설을 $\alpha = 0.05$로 검정하라.

힌트: 공정한 주사위라면 각 면의 기대 도수는 $600/6 = 100$. 자유도는 $k-1 = 5$.

아래 셀에서 직접 계산해 보십시오.

import numpy as np from scipy import stats # === 자료 === observed = np.array([92, 110, 105, 88, 97, 108]) n_total = observed.sum() k = len(observed) # ============ # 공정한 경우 기대 도수 — 직접 작성 # expected = ? # 카이제곱 통계량 — 직접 작성 # X2 = ? # p-값 — 직접 작성 # p_value = ? print(f"관측 합계: {n_total}") print(f"범주 수: {k}")
정답 및 풀이 보기

기대 도수 $E_{i} = 100$ (모든 $i$). $X^{2} = \sum (O_{i}-100)^{2}/100 \approx 3.86$, $df = 5$, $p$-값 $\approx 0.570$. $H_{0}$(주사위 공정)을 기각하지 못한다.

import numpy as np from scipy import stats observed = np.array([92, 110, 105, 88, 97, 108]) n_total = observed.sum() k = len(observed) # 공정한 주사위라면 모든 면의 확률이 1/6 expected = np.full(k, n_total / k) X2 = ((observed - expected)**2 / expected).sum() df = k - 1 p_value = 1 - stats.chi2.cdf(X2, df) print(f"기대 도수: {expected}") print(f"X^2 = {X2:.4f}") print(f"자유도 df = {df}") print(f"p-값 = {p_value:.4f}") print(f"결론: H0(주사위 공정)을 {'기각' if p_value < 0.05 else '기각하지 못한다'}") # scipy 내장 함수와 비교 chi2_stat, p_val = stats.chisquare(observed, expected) print(f"\nscipy 결과: X^2 = {chi2_stat:.4f}, p = {p_val:.4f}")
SECTION 6.4

이원분할표에서의 독립성 검정

일원분할표에 대한 카이제곱 검정을 두 변수가 동시에 분류된 이원분할표(two-way table)로 확장하여, 두 범주형 변수가 독립인지를 검정할 수 있다.

6.4.1 이원분할표에서 기대 도수의 계산

기대 도수 공식 독립성 가정 하에 $i$행 $j$열의 기대 도수는 다음과 같다. $$E_{ij} = \frac{(\text{행 } i \text{ 합계}) \times (\text{열 } j \text{ 합계})}{\text{전체 합계}}$$ 자유도: $df = (R-1)(C-1)$

6.4.2 iPod 판매자 실험

중고 iPod 판매자가 화면 결함을 알고 있는 상태에서, 질문 형식이 결함 공개에 영향을 미치는지를 검정한다. 219명을 세 그룹에 무작위 배정하여 다음과 같이 질문하였다.

  1. 일반(General): "iPod에 문제가 있습니까?"
  2. 긍정 가정(Positive Assumption): "문제가 무엇입니까?"
  3. 부정 가정(Negative Assumption): "문제가 없습니까?"
일반긍정 가정부정 가정합계
문제 공개2233661
문제 숨김715037158
합계737373219
예제 6.40
독립성 검정의 수행
[문제] 질문 형식과 공개 여부가 독립이라는 귀무가설을 검정하라.
풀이 보기

가설: $H_{0}$ — 두 변수가 독립이다, $H_{A}$ — 종속이다.

기대 도수: 공개 행 기대값 $61 \times 73 / 219 \approx 20.33$ (모든 열 동일), 숨김 행 기대값 $\approx 52.67$.

$X^{2}$: $16.53 + 0.35 + 12.06 + 6.38 + 0.14 + 4.66 \approx 40.13$

자유도: $df = (2-1)(3-1) = 2$, $p$-값 $\approx 2 \times 10^{-9}$

결론: $H_{0}$을 강하게 기각한다. 질문 형식이 결함 공개에 영향을 미친다는 강한 증거가 있다.

import numpy as np from scipy import stats # 관측 분할표: [공개, 숨김] x [일반, 긍정, 부정] observed = np.array([ [ 2, 23, 36], # 공개 [71, 50, 37], # 숨김 ]) chi2, p_value, dof, expected = stats.chi2_contingency(observed) print("관측 도수:") print(observed) print("\n기대 도수 (독립성 가정 하):") print(np.round(expected, 2)) print(f"\nX^2 = {chi2:.3f}") print(f"자유도 df = {dof}") print(f"p-값 = {p_value:.2e}") print(f"결론: H0(독립)을 {'기각' if p_value < 0.05 else '기각하지 못한다'}")
새로운 시각: iPod 실험의 심리학적 통찰

이 실험은 질문 프레이밍 효과(question framing effect)의 강력한 사례이다.

  • 일반 질문 — 공개율 $2/73 = 2.7\%$
  • 긍정 가정 — 공개율 $23/73 = 31.5\%$
  • 부정 가정 — 공개율 $36/73 = 49.3\%$

해석: 일반 질문은 판매자에게 문제를 숨길 "탈출구"를 제공한다. 긍정 가정 질문("문제가 무엇입니까?")은 문제가 있다고 가정하므로 거짓말의 심리적 비용을 높인다. 부정 가정 질문("문제가 없습니까?")은 직접적인 부정 진술을 요구하므로 가장 강한 압력으로 작용한다.

실용적 적용: 감사 절차, 법적 심문, 의료 면담, 설문조사 설계에서 질문 형식의 미묘한 변화가 정보 공개율을 18배 이상 증가시킬 수 있음을 시사한다.

새로운 시각: 카이제곱 검정 vs Z-검정의 선택

학생들은 종종 언제 카이제곱 검정을 사용하고 언제 $Z$-검정(단일/두 비율)을 사용해야 하는지 혼란스러워한다.

상황권장 방법
단일 비율과 특정 값 비교$Z$-검정 (단일 비율)
두 그룹의 비율 비교$Z$-검정 (두 비율) 또는 $2 \times 2$ 카이제곱
3개 이상 그룹의 비율 비교카이제곱 검정
이론 분포 적합도 검정카이제곱 검정
두 범주형 변수의 독립성카이제곱 검정

중요한 관계: $2 \times 2$ 분할표에서 $X^{2} = Z^{2}$가 성립하며, 두 검정은 동일한 $p$-값을 산출한다.

선택 기준: 방향성(어느 그룹이 더 높은지)에 관심이 있으면 $Z$-검정이 더 정보적이다. 단순히 차이의 유무가 관심이라면 두 방법 모두 적합하다.

아래 셀로 직접 분할표 자료를 입력하여 카이제곱 검정을 수행해 보십시오. 행과 열의 개수도 자유롭게 변경할 수 있다.
import numpy as np from scipy import stats # === 자유롭게 변경할 분할표 === # 예: 행 = 처치, 열 = 결과 table = np.array([ [ 2, 23, 36], [71, 50, 37], ]) # ============================== chi2, p_value, dof, expected = stats.chi2_contingency(table) print("관측 도수:"); print(table) print("\n기대 도수:"); print(np.round(expected, 2)) print(f"\n행/열: {table.shape}, df = {dof}") print(f"X^2 = {chi2:.3f}, p-값 = {p_value:.2e}") # 모든 기대 도수가 5 이상인지 점검 ok = (expected >= 5).all() print(f"\n조건(모든 기대 도수 >= 5): {'충족' if ok else '미충족'}")
연습문제 6.4
금연 지원 그룹 효과

금연 시도자 300명을 두 그룹에 무작위 배정하였다. 결과는 다음과 같다.

금연 성공금연 실패합계
패치 + 지원 그룹40110150
패치만30120150
합계70230300

지원 그룹 추가가 금연율과 독립이라는 귀무가설을 $\alpha = 0.05$로 검정하라.

힌트: $E_{ij} = (\text{행 합계}) \times (\text{열 합계}) / 300$. $df = (2-1)(2-1) = 1$.

아래에서 직접 계산해 보십시오.

import numpy as np from scipy import stats # === 분할표 === observed = np.array([ [40, 110], # 패치 + 지원 [30, 120], # 패치만 ]) # ============== # 직접 작성: 기대 도수, X^2, p-값 # chi2, p_value, dof, expected = ?
정답 및 풀이 보기

기대 도수 $E_{11} = E_{21} = 35$, $E_{12} = E_{22} = 115$. $X^{2} \approx 1.86$, $df = 1$, $p$-값 $\approx 0.172$. $\alpha = 0.05$에서 $H_{0}$을 기각하지 못한다. 지원 그룹 효과가 통계적으로 유의하다는 충분한 증거가 없다.

import numpy as np from scipy import stats observed = np.array([ [40, 110], [30, 120], ]) chi2, p_value, dof, expected = stats.chi2_contingency(observed) print("기대 도수:") print(np.round(expected, 2)) print(f"\nX^2 = {chi2:.4f}") print(f"df = {dof}") print(f"p-값 = {p_value:.4f}") print(f"결론: H0(독립)을 {'기각' if p_value < 0.05 else '기각하지 못한다'}") # 2x2이므로 z-검정과 동등함을 확인 n1 = observed[0].sum(); x1 = observed[0,0] n2 = observed[1].sum(); x2 = observed[1,0] p_pool = (x1 + x2) / (n1 + n2) se = np.sqrt(p_pool*(1-p_pool)*(1/n1 + 1/n2)) z = (x1/n1 - x2/n2) / se print(f"\nz-검정과의 비교:") print(f"Z = {z:.4f}, Z^2 = {z**2:.4f} (X^2와 일치)")

import numpy as np from scipy import stats print("=" * 50) print("제6장 종합 도구함") print("=" * 50) # (A) 단일 비율 신뢰구간 def one_prop_ci(x, n, conf=0.95): p = x/n se = np.sqrt(p*(1-p)/n) z = stats.norm.ppf((1+conf)/2) return p, (p - z*se, p + z*se) # (B) 단일 비율 검정 def one_prop_test(x, n, p0): p = x/n se = np.sqrt(p0*(1-p0)/n) z = (p - p0)/se return z, 2*(1 - stats.norm.cdf(abs(z))) # (C) 두 비율 검정 def two_prop_test(x1, n1, x2, n2): p1, p2 = x1/n1, x2/n2 p_pool = (x1 + x2)/(n1 + n2) se = np.sqrt(p_pool*(1-p_pool)*(1/n1 + 1/n2)) z = (p1 - p2)/se return z, 2*(1 - stats.norm.cdf(abs(z))) # (D) 카이제곱 검정 — scipy 내장 활용 print("\n예시 사용:") p, ci = one_prop_ci(40, 200, 0.90) print(f"흡연율 90% CI: 점추정={p:.3f}, 구간=({ci[0]:.3f}, {ci[1]:.3f})") z, pv = two_prop_test(14, 40, 11, 50) print(f"CPR 두 비율 검정: Z={z:.3f}, p={pv:.4f}") table = np.array([[40, 110], [30, 120]]) chi2, pv, df, exp = stats.chi2_contingency(table) print(f"금연 분할표: X^2={chi2:.3f}, df={df}, p={pv:.4f}")
